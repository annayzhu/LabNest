## 失败与未执行

初次检查失败记录保留在 browser-review.log、初轮测试及视觉日志：旧脚本找不到收起的控件、CFU关闭效率空值、B管自定义依据/A管辅助试剂定位、移动端大工具继承正文边距均已修复或适配并重新验证。Vancouver初轮一次既有性能阈值受并发构建影响，单独重跑与最终双时区完整运行通过。

尚未执行：真实桌面200%缩放、手机100/160%缩放、真实软键盘与中文输入法、原生下拉菜单四角录像、实验人员试用、用户原故障记录和物理打印。它们影响对应设备/人员场景的最终验收，不能标成通过，也不阻止已完成代码与自动证据交付。

手机HTTP入口不提供受信任HTTPS条件；localhost离线测试不能冒充手机HTTPS离线认证。

## 可直接复验

1. 手机打开交付网址，在Tools进入Calculator。以Master Mix载入示例，切换组，修改数值后计算；确认单位与数字同排，输入与结果能互返。
2. 将手机页面缩放设为160%，检查短名称、长名称、单位及下拉菜单，打开软键盘输入`1.25e-6`与中文名称；观察焦点和计算按钮能否滚动到。
3. 转染切到B管，将“自定义方案依据”的每孔依据量留空，再切A管计算；应回到B管缺失字段。A管辅助试剂用量缺失应定位A管。
4. 电脑浏览器原生200%缩放检查Master Mix、Tm、批量样本和转染；不使用网页CSS缩放代替。
5. 一位实验人员用实际已确认方案完成一次配液，核对每孔与整批量、模板单独加入、警告和复制内容；记录设备、版本、问题步骤，不录入敏感样本身份。
