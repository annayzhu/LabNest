| 入口 | 实际行为 | 状态 |
|---|---|---|
| reagent-dosing | dilution/final；10mM→10µM、2mL，取液2µL，回读本机历史 | 通过：两浏览器两视口 |
| fold-dilution | dilution/fold；10×→1×、2mL，取液200µL，1e-9µL浮点容差 | 通过：两浏览器两视口 |
| Tools / Today | 实际点击当前目录和反应配液，检查标题及分段控件 | 通过 |
| Run桌面抽屉 | 合成Run触发图标、共享select和Workbench iframe | 通过 |
| LabNest孔板嵌入 | 共用Workbench，上下文、写回与示例/错误拒写回归 | 通过 |
| FreePlate六适配器 | seeding/hydrogel/kill-curve/fold-dilution/master-mix/moi；逐一计算、改值失效、selector、Escape、无动画 | 通过：两浏览器两视口 |
