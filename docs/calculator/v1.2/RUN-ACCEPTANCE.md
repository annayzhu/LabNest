## 数据链路

复用 ProtocolDocument → projectProtocolDocument → ProtocolStep 的 source_ref/content_blocks → buildProtocolExperimentSteps → 已有 protocolSnapshotJson → runStepContent → 已有 ProtocolContentBlockView。步骤引用为版本ID＋源块ID，不能用标题合并同名步骤。共享准备块由同一捕获文档解析。

旧序号引用只在捕获的同版本内容与原步骤投影可核对时恢复；不读取最新Protocol库替换历史。仅文字快照保留文字并提示缺少格式。单测恢复夹具1个、纯文本夹具1个；未检查或回填生产历史，不能把合成样例比例当成历史恢复率。

当前表格模型不含合并单元格关系；没有伪造此能力。未归属的非文字块作为公共内容；标题前独立文字仍沿用现有步骤投影，尚未全面验证所有公共准备排版。未解析参数保留占位；附件离线缓存不作保证。

## 可重复证据

- `evidence/run-fixture.json`：完整合成源节点。
- `evidence/run-browser-report.json`：真实创建URL、非第一步ID、尺寸和操作记录。
- `evidence/v12-database-report.json`：冻结快照、步骤关联、计时及备注状态。
- `evidence/run-{320,360,390}.png` / `run-wide-{320,360,390}.png`：真实渲染截图，浏览器模拟视口。
- `evidence/followup-report.json`：一次明确注入的503、真实后端重试与同ID回放。首次503是受控故障注入，不冒充真实服务器故障。

完整页截图会包含固定底部导航在截图拍摄位置的覆盖；滚动断言验证了最后行可达，不把一张截图当作全部交互验收。
