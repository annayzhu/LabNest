## Problem Statement
科研用户反馈正文图片保存后不可见、打印空白、中文图注选词受阻，图片属性常驻且元数据边距不一致。基线 main 3d834d0。共享代码缺陷不等同所有记录丢图；数据保留引用不等同图片实际可见。

## Solution
保留现有正文模型和附件系统，按各入口实际保存/读取/编辑/打印链路定位并修复。阅读时突出图片及图注，选中时提供简洁编辑操作，低频设置按需展开。元数据与Protocol工作台对齐。

## User Stories
1. As a 科研用户, I want 插入图片后保存刷新仍能看到原图, so that 实验记录可信。
2. As a 科研用户, I want 重新编辑保留图片引用、图注和宽度, so that 修改不丢失内容。
3. As a 阅读者, I want 只读页面实际加载图片, so that 保存成功提示不掩盖显示故障。
4. As a 文档作者, I want 打印和PDF保留标题、正文及图片, so that 输出不是空白。
5. As a 中文用户, I want 拼音候选词用回车确认, so that 图注不会被表单拦截或意外提交。
6. As a 中文用户, I want 中英文混输和修改后保存图注, so that 科研术语与中文说明完整。
7. As a 编辑者, I want 仅选中图片时出现简洁工具条, so that 正文不被属性框占据。
8. As a 编辑者, I want 按需调整尺寸和替换图片, so that 低频功能仍可找到。
9. As a 键盘用户, I want 图片编辑操作可聚焦并有明确名称, so that 简化不损害可访问性。
10. As a 阅读者, I want 普通阅读只显示图片和图注, so that 编辑属性不混入正文。
11. As a 科研用户, I want 图片失败有明确重试与原图入口, so that 可区分请求故障和原图丢失。
12. As a 手机用户, I want 图片、工具条和元数据不横向溢出, so that 小屏仍可操作。
13. As a 用户, I want 元数据宽度、内边距与上方工具栏对齐, so that 各入口一致且不贴边。
14. As a 实验作者, I want 实验正文完成全部往返链路, so that 记录可持续编辑。
15. As a 研究计划作者, I want 计划正文完成同样链路, so that 计划图片可复用。
16. As a 结果作者, I want 结果正文图片和图注可靠, so that 结果可审查。
17. As a 报告作者, I want 报告图片能读取和打印, so that 汇报可交付。
18. As a Protocol作者, I want 保留不可变版本和图片来源, so that 修复不改写历史。
19. As a 随手记录用户, I want 快速插图保存刷新正常, so that 临时观察不丢失。
20. As a 模板作者, I want 结果模板说明图片可保存和显示, so that 后续使用模板清楚。
21. As a Run用户, I want 冻结步骤中的图片实际加载且归属正确, so that 执行不串图。
22. As a 维护者, I want 按入口记录通过、失败、未执行, so that 共享组件修复不被夸大为全站通过。
23. As a 用户, I want 原附件与历史快照不被修复脚本覆盖, so that 科研证据安全。
24. As a 用户, I want 真机中文输入和打印限制明确, so that 模拟事件不被冒充真机验收。

## Implementation Decisions
- 复用共用媒体节点、只读媒体视图、表单回车处理和文档工作台样式。
- 图片引用和原始附件继续分离；不重建附件或正文系统，不批量重写历史。
- 按需媒体操作保留删除引用、替换、宽度和图注；打印排除交互控件。
- 避免宽泛打印选择器隐藏包含正文的祖先。
- 图片故障先查看实际请求，必要时保留预览失败到原图的可恢复路径；不假定所有入口都失败。

## Testing Decisions
- 采用用户已明确的最高层边界：八类实际页面的插图→保存→刷新→重新编辑→只读查看→打印/PDF。
- 每个纵向切片先产生失败的公开行为测试，再实施最小修复。
- 复用现有媒体页面验证脚本的隔离数据库和合成记录；断言图片加载、可见正文、图注与真实PDF，不仅断言JSON。
- 中文输入自动化验证composition/Enter事件，中英文修改和保存；物理输入法完整交互单独标记。
- 桌面/手机一次批量视觉检查，集中修复后最多一次确认；完整测试、类型检查和生产构建收尾。

## Out of Scope
- 全新编辑器、附件存储系统或全站主题重设计。
- 未确认故障记录的历史内容自动迁移或删除原图。
- 把模拟手机视口或composition事件当作真机输入法验收。
- 本次不自动合并或部署正式环境。
