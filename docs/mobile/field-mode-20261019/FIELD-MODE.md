# 现场模式入口（2026-10-19）

基线：`67c7e36a`（第 3 批已发布到 3001）。起因：用户录宣传视频前指出，手机、iPad 和 Apple Watch 的入口很难找，手表配对尤其难找；现场模式的按钮应放在主页一个好找的地方。

## 原来的样子（去重前）

- 同一个"去实验台"的入口有五种叫法，分在四处：主页快捷入口"Experiment run mode"、主页"All runs / View runs"、侧栏和顶栏"Runs"、实验列表"Run mode"，都指向标题为"Protocol Run"的列表页；执行页和实验详情页另有"台面模式"。
- 平板或手机只能手输网址打开；电脑用 localhost 打开时，别的设备根本无从得知地址。
- 手表配对藏在执行页中部的折叠框"Apple Watch 执行端 · 预览"里，只在带体系的实验中出现；框里还留着写给开发者的说明（"尚需你的真机验收"）。

## 决定（Q74–Q79，按推荐）

| 编号 | 问题 | 决定 |
|---|---|---|
| Q74 | 名称 | 统一叫"现场模式"，取代上面五种叫法和"台面模式"。 |
| Q75 | 主页入口 | 电脑主页页头右侧、手机主页第一屏各放一个醒目的"进入现场模式"（主色）；点开是现场模式页：列出计划中和进行中的实验，每个实验"在这台设备上打开"或"其他设备"。原 `/protocol-run` 页改为现场模式页，地址不变。 |
| Q76 | 发到平板或手机 | "其他设备"面板显示二维码，扫码直接打开该实验的现场模式（`/experiments/[id]/run?view=bench`），附可复制的链接。二维码在本机生成（`qrcode` 包），不经过外部服务。电脑用 localhost 打开时先请用户填一次局域网地址，记在这台电脑上（`localStorage` `labnest:lan-origin`）。 |
| Q77 | 手表配对 | 同一面板的手表卡片：大字分组显示 12 位配对码、10 分钟倒计时、服务器地址与三步说明；面板打开期间每 3 秒查一次连接状态，手表连上后显示"手表已连接"和"断开手表"。执行页中部的旧折叠框删除。手表 App 提示改为"在电脑或手机的现场模式中生成配对码"。配对码格式不变。 |
| Q78 | 执行页 | 页头依次是"进入现场模式／退出现场模式""其他设备""现场模式"（返回列表）"实验记录"。 |
| Q79 | 手表卡片的显示范围 | 所有实验都显示手表卡片；规程不是步骤块格式时写明"旧格式规程，手表暂不支持"，实验已提交或已结束时写明不能配对。 |

## 做了什么

- `src/lib/field-mode.ts`（新）：本机地址判断、局域网地址规范化、现场模式链接、配对码分组。测试 `field-mode.test.ts`（5 项）。
- `src/components/FieldDevices.tsx`、`field-devices.css`（新）：设备面板（二维码、局域网地址、手表配对与连接状态）和主页入口样式。
- `src/lib/watch-execution.server.ts`：`createWatchPairing` 同时返回过期时间；新增 `watchConnection`（最近一次认领未过期且其后未断开即为已连接）。`run/actions.ts`：`connectWatchRun`／`disconnectWatchRun` 改为直接调用，新增 `watchRunConnection`。
- 主页、现场模式页、执行页、实验详情页、实验列表、侧栏、顶栏改名并接入面板；`WatchRunConnection.tsx` 移入废纸篓。
- 手表 App：配对页提示文字。

## 录制前的显示修正（演示中会出现的问题）

宣传视频的演示数据暴露了几处显示问题，一并修正：

- 库存：列表、条目页、移动端与流水中的数量改用全站数量显示规则（`formatQuantity`），不再出现 4.4719999999999995 mL；流水备注里的内部 ID 换成实验编号与步骤（`inventoryNoteText`）。执行页的库存交易同样格式化。
- 规程使用记录：表格不再把侧栏撑出屏幕（`.ln-usage-wrap { contain: inline-size }`）；选择项写成"体系：▲ 20 µL · 新引物：否"；"0 次主要执行"改为统计所有用到该版本的实验（"N 个实验"）。
- 步数：实验详情页、编辑页侧栏、主页进行中实验和现场模式列表只计本次适用的步骤（`runStepProgress`、`runProgressFromSource`），不再出现 23/25。
- 准备清单：多个规程时步骤写成"PRT-100003 第 1 步"；1000 及以上的用量换到下一级单位（2000 µL → 2 mL，`benchAmount`）。
- 中文界面：主页快捷入口按语言在服务端翻译（逐字动画让整页翻译匹配不到）；补上"现在没有进行中的实验……""今天没有安排实验。""步骤已全部完成"。
