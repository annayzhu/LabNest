# iPad 铺满屏幕与平板布局

日期：2026-11-02  
来源：用户反馈“ipad现在的display 是手机的比例 不能完全填充ipad的界面，这个UI需要重新修改”。  
基线：`main` 6d32846b；开发目录与 `origin/main` 为 0/0；3001 运行 `labnest-app:lan-ids-6d32846b`。  
状态：Q343–Q354 用户已确认按推荐（2026-11-02）；已实施，在 3005（克隆库 `labnest_ipad_20261102`）和 iPad 模拟器上验证；用户已验收（2026-11-02），发布到 3001。

## 1. 查到的原因

问题有两层，需要一起改，只改一层仍然不像 iPad 应用。

**第一层：原生 App 只声明了 iPhone。**  
`LabNestMobile` 和锁屏计时扩展 `LabNestTimers` 的 `TARGETED_DEVICE_FAMILY = 1`（只有 iPhone）。iPad 因此用 iPhone 兼容模式运行：画面是放大的手机窗口，两侧露出桌面壁纸。  
已在 iPad Air 11 英寸模拟器上复现，截图见 `before/native-ipad-air11-portrait.png`。

**第二层：网页把 1024 px 以下都当手机。**  
App 里显示的就是 3001 的网页。网页外壳在宽度小于 1024 px 时，显示手机版：底部四个标签、☰ 抽屉和页首 ··· 菜单。  
iPad 竖屏宽度如下，都小于 1024 px：

| 机型 | 竖屏宽度 |
|---|---|
| iPad mini | 744 |
| iPad / iPad Air 11 | 820 |
| iPad Pro 11 | 834 |

所以 App 改成 iPad 原生之后，竖屏仍会得到拉宽的手机界面。

用 WebKit 按 iPad 尺寸截了 3001（只读访问），截图在 `before/`：

- **现场模式，820×1180 竖屏**（`web-bench-820x1180.png`）：步骤清单在上，当前步骤在第一屏以下，要往下滚才看得到。
- **首页 744 竖屏，实验详情 820 竖屏**：都是手机版单列，右侧没有信息栏。
- **现场模式，1180×820 横屏**（`web-bench-1180x820.png`）：页首按钮放不下，“实验记录”被截掉一半。
- **1024 px 以上**：电脑版布局，基本可用。

**已确认不需要改的。**
- 网页没有按 User-Agent 区分设备。
- 锁屏计时在启动实时活动前已检查 `areActivitiesEnabled`，所以在 iPad 上不会出错。
- 手表 App 不受影响。

## 2. 待确认问题

**Q343 App 支持 iPad。**  
推荐：
- `LabNestMobile` 和 `LabNestTimers` 的设备类型改为 iPhone + iPad（`1,2`），iPad 上全屏显示。
- iPhone 的构建和行为不变；手表的两个 target 不动。
- `project.pbxproj` 里现有的未提交改动只是 Xcode 重新排序。提交时只带入本批的设备类型和方向设置，不混入这些改动。

**Q344 方向与多任务。**  
推荐：
- iPad 支持全部四个方向（含倒置竖屏）。
- 支持分屏浏览、侧拉和台前调度，不设 `UIRequiresFullScreen`。
- 窗口宽度小于 744 px 时（侧拉、三分之一分屏），网页自动用手机布局；更宽时用下面的平板布局。
- iPhone 维持现有三个方向。

**Q345 平板布局从多宽开始。**  
推荐：手机版和电脑版的分界从 1024 px 改为 744 px，这样 iPad mini 竖屏也算平板。

744–1023 px 是新的“平板”区间：
- 没有底部标签栏、☰ 抽屉和页首 ··· 菜单。
- 左侧是图标侧栏（72 px，就是现有侧栏的收起状态）。
- 顶栏用电脑版：搜索、AI、中英切换。
- 页首按钮直接显示。

实现方式：在 Tailwind 里加一个 `tablet` 断点（744 px）。只把表示“手机还是电脑”的地方改用这个断点，包括外壳、顶栏、··· 菜单、页首按钮，以及只在电脑显示的上传框等，约 27 个文件 61 处 `lg:`，外加 CSS 里的 1023/1024 查询。纯栅格列数（如 `lg:grid-cols-3`）不改。  
这条规则按宽度判断，所以电脑浏览器窗口缩到 744–1023 px 时也会是这个样子。  
备选：用 Tailwind 现成的 768 px，代价是 iPad mini 竖屏仍为手机版。

**Q346 平板区间的侧栏。**  
推荐：
- **竖屏（744–1023 px）：** 默认只显示图标。点展开按钮后，完整侧栏浮在页面上方，背后加半透明遮罩，页面不重排。选好页面或点遮罩后收起。
- **横屏（1024 px 及以上）：** 与现在的电脑版一致，224 px 宽，可收起，且记住收起状态。
- 竖屏的图标侧栏不受这个“记住收起”设置影响。

**Q347 现场模式在 iPad 上的布局。**  
推荐：从 744 px 起改为左右两栏：左边是步骤清单，右边是当前步骤。

- **左栏：** 宽 15–17 rem，固定在视口内，可单独滚动。
- **右栏：** 当前步骤占满剩余宽度。“计算器 / 计时 / 记一笔”和“上一步 / 全部步骤 / 下一步”的按钮高度不低于 44 px，方便戴手套点按。
- **横屏：** 同样两栏，右栏更宽，不另加第三栏。
- **其余不变：** 现场模式的紧凑原则不变；准备工作仍是收起的一条。

**Q348 页首按钮放不下。**  
推荐：在共用的页首组件里修，所有页面一起受益。
- 标题和按钮放不下时，按钮整体换到下一行，不再被截断。
- 现场模式页首的五个按钮：“保持屏幕常亮”“退出现场模式”“其他设备”始终可见；“返回现场模式”“实验记录”在 1280 px 以下收进 ···。

**Q349 其他页面的平板布局范围。**  
推荐：本批按 Q345 统一切换外壳后，逐页检查以下页面，有挤压、截断或空白过大的就修：
- 首页、实验列表、实验详情、现场模式
- 记录列表和记录详情
- 规程
- 库存首页和库存清单
- 样本和样本盒
- 计算器、工具、设置

检查尺寸：竖屏 744、820、834、1024；横屏 1133、1180、1366。

具体要求：
- 首页在平板上用电脑版概览（进行中实验、今日安排、日历），不用手机卡片。
- 实验详情的右侧信息栏（执行控制、附件、活动）：竖屏从按钮打开，从右侧滑出；横屏宽度够时与现在一样常驻。
- 不在本批的：编辑器内部工具、绘图工作台、设计工作台的细节布局。检查时如果这些地方出现截断，单独记录，另开一批处理。

**Q350 App 内网页使用桌面级浏览。**  
推荐：保持 iPadOS 默认的桌面级浏览，不强制手机模式。好处有三点：
- 外接键盘时 ⌘K 搜索可用；
- 触控板悬停提示可用；
- 页面按真实宽度排版。

**Q351 iPad 上的“连接你的 LabNest”设置页。**  
推荐：
- 表单居中，最大宽度 560 pt，不在横屏拉满整行。
- 扫码界面全屏显示。
- iPhone 不变。

**Q352 iPad 上的计时提醒。**  
推荐：iPadOS 没有锁屏实时活动和灵动岛，所以 iPad 只发“计时结束”通知。
- 代码已有判断，不加新的提示文字。
- 在 `native/LabNestMobile/README.md` 写明这一区别。

**Q353 验证方法。**

## 4. 实施

**原生 App（Q343、Q344、Q351、Q352）**
- `LabNestMobile`、`LabNestTimers` 的 `TARGETED_DEVICE_FAMILY` 改为 `"1,2"`，Debug 和 Release 都改。`project.pbxproj` 里 Xcode 重新排序的那几行不在本批提交内。
- `Info.plist` 新增 `UISupportedInterfaceOrientations~ipad`，四个方向都支持。没有设 `UIRequiresFullScreen`，所以分屏浏览、侧拉、台前调度和 iPadOS 26 的窗口模式都可用。
- `ServerSetupView`：表单最大宽度 560 pt，在页面中居中。iPad 上的扫码改为全屏显示，iPhone 仍用原来的弹出页。
- `README.md` 增加 iPad 一节，并写明 iPad 上只有“计时结束”通知。

**网页（Q345–Q349）**
- **新断点。** `globals.css` 增加 Tailwind 断点 `tablet`（46.5rem = 744 px）。以下原本用 `lg:` 区分手机和电脑的地方，改为用 `tablet:`：
  - 外壳：`AppShell`、`Sidebar`（含底部栏和抽屉）、`TopBar`、`MobilePageMenu`；
  - 首页和 `MobileToday`；
  - 速记：`entries/new`、`EntryComposer`；
  - 库存：库存清单、`MobileInventoryBench`、`InventoryCategories`、`InventoryHome`；
  - 执行：执行页的上传框、`RunStepSelection`、`ProtocolRunProgressForm`；
  - 其他：`MeasurementCapture`、`OfflineCompanion`。
  - 侧栏和 `MobilePageMenu` 读取窗口宽度时共用 `src/lib/use-media-query.ts`。
  - 纯栅格列数仍用 `lg:`。CSS 里给手机底部栏让位的两处查询从 1023 px 改为 743.98 px，`.ln-field-entry` 从 1024 px 改为 744 px。
- **侧栏（Q346）。** 宽度在 744–1023 px 时：
  - 侧栏默认是 72 px 的图标栏；页面还没测量宽度时，CSS 也先按图标栏显示，避免闪一下展开的侧栏；
  - 点 ⟩ 后，224 px 的完整侧栏浮在页面上方，加遮罩；页面不重排；
  - 点遮罩、按 Esc 或选择页面后收起；
  - 展开按钮的触控范围是 44 px。
  - 1024 px 及以上与原来一致。
- **现场模式（Q347）。** 从 744 px 起分两栏：
  - 步骤清单宽度：744–1023 px 为 15 rem，1024–1279 px 为 17 rem，1280 px 及以上保持原样；
  - 步骤清单固定在顶栏下方，单独滚动；
  - 这个宽度下“全部步骤”按钮隐藏（清单就在旁边），上一步、下一步两按钮平分一行。原来电脑上点“全部步骤”没有反应的问题也一起消失。
- **页首（Q348）。**
  - 768 px 及以上，标题和按钮放不下一行时，按钮整体换到下一行并靠右，不再被截断。原来在 1024 px 以上强制按钮不换行的规则已删除。
  - 执行页的“现场模式”“实验记录”在 1280 px 以下收进 ···（`RunPageMenu`）。手机上 ··· 里只有“实验记录”，因为底部栏已有现场模式。
- **详情（Q349）。** 宽度在 744–1279 px 时：
  - 顶栏出现“详情 / Details”按钮，只在有侧栏的页面显示（实验、记录、结果、规程、研究方案、报告）；
  - 点开后，原侧栏从右侧滑出，宽 24 rem，加遮罩；
  - 点遮罩、按 Esc 或换页后关闭；
  - 打印不受影响。
  - 实现时没有改这六个页面的代码，因此没有动另一个会话正在改的 `entries/[id]/page.tsx`。

## 5. 验证（2026-11-02）

**测试环境**
- 克隆库 `labnest_ipad_20261102`，开发服务 3005（launch 配置 `labnest-ipad`，`LABNEST_BUILD_DIR=.next-ipad`）。
- 为了让记录详情能打开，在克隆库上执行了另一会话未提交的 `20261102150000_copilot_suggestions` 建表 SQL。正式库没有改动。

**网页**
- **方法：** Playwright WebKit，触屏模式，User-Agent 与 App 相同，注入 `window.labnestNative`。
- **尺寸：** 390、744、820、834、1024 竖屏，1133、1180、1366 横屏，以及 1440 电脑。
- **页面：** 首页、实验列表、实验详情、现场模式、记录详情、库存首页、库存清单、记录列表、规程、样本、工具、设置、速记，共 13 个，每个尺寸都看。
- **结果：**
  - 所有尺寸 `scrollWidth` 都等于视口宽度，没有横向溢出。
  - 744–1023 px：侧栏 72 px，没有底部栏。
  - 1024 px 及以上：侧栏 224 px。
  - 390 px：仍是手机布局。
  - 原来 1180 横屏执行页被截断的“实验记录”按钮已不再截断。
  - 剩下的“越界”元素都在横向滚动条里：设置的分区条、库存标签条、记录的项目条。这些条带在改动前就会横向滚动。
- **交互（820×1180）：**
  - 侧栏：展开后浮在页面上，内容区仍从 72 px 开始；选“库存”后跳转并收起。
  - 详情：从右侧滑出，点遮罩关闭。
  - 执行页 ···：820 px 时有“现场模式、实验记录、离线使用”三项；1440 px 时这两项回到页首，菜单里隐藏；390 px 的 ··· 里只有“实验记录”。

**原生 App**
- **构建：** iOS 模拟器构建成功。生成的 `Info.plist` 中，App 和 `LabNestTimers` 的 `UIDeviceFamily` 都是 `[1, 2]`。
- **竖屏：** iPad mini（744×1133）、iPad Air 11（820×1180）、iPad Pro 13（1032×1376）都铺满全屏，没有壁纸边。截了首页、现场模式和实验详情：
  - mini 和 Air 11：图标侧栏、两栏现场模式；
  - Pro 13：完整侧栏。
- **横屏：** Air 11 横屏截了现场模式、实验详情和连接设置页，设置页表单居中。mini 和 Pro 13 横屏以网页 1133×744、1366×1024 截图为准，模拟器旋转需要你在模拟器面板里授权。
- **窄窗口：** iPadOS 26 的窗口模式下，Air 11 恢复了之前 iPhone 兼容模式留下的窄窗口（约 660 pt），页面自动换成手机布局，和 Q344 一致（`after/app-ipad-air11-narrow-window.png`）。用窗口按钮“填满”后即为全屏平板布局。
