# 手机 App 与手表 App（2026-10-21）

基线：先在 `b7e16ef4` 上开发；2026-10-21 晚本目录同步到 GitHub `origin/main` `1ffb6b3e`（#107–#121）后，在其上重新核对（见“与 GitHub 主分支对齐”）。起因：用户想把 LabNest 做成手机和手表上的 App，交互照着 Notion 做。

## 原来的样子

- 手机：网页已适配手机（现场模式、快速记录、底部导航 Today · Run mode · Records · Inventory · More）。iPhone App 只把配对码转给手表，看 LabNest 要跳到 Safari。
- 手表：原生 App，步骤、计时、配液卡、完成步骤；每个实验在网页生成 4 位码配对一次。
- 服务器在 Mac 上，局域网 HTTP，换网络 IP 就变；没有登录；Personal Team 签名约一周过期。

## 参照：Notion 的做法

Notion 的手机 App 起步就是网页套壳（Cordova + 网页视图），之后一块块换成原生，先换的是首页标签（2022 年，iOS 启动快 2 倍、Android 快 3 倍），没有整体重写；移动团队 11 人。没有官方 Apple Watch App。手机交互：底部栏（首页 · 搜索 · 收件箱 · 新建）、左上角侧栏页面树、键盘上方工具栏、长按块拖动、右上角 ··· 收起页面操作。

## 做了什么

### 网页（手机交互，Q112–Q116）

- **底部栏**（`Sidebar.tsx`）：首页 · 搜索 · 现场模式 · ＋新建。原来的"记录""库存""More"去掉；左上角 ☰ 打开侧栏（`MobileDrawer`），内容与电脑侧栏相同，另加记录时间线；沿用 #109 的手机命名：时间线叫"记录历史"、Entries 叫"全部记录"；首页和搜索已在底部栏，不重复。语言切换在侧栏底部。
- **顶栏**（`TopBar.tsx`）：模块页左上角 ☰，子页面 ←；标题为所在模块；右侧 AI 与 ···。顶栏的搜索按钮删除（底部栏已有）。
- **···**（新 `MobilePageMenu.tsx`）：手机上页头的操作（`PageHeader` 的 actions、文档编辑器的导出 / 打印 / 附件包、Protocol 编辑器除"保存"外的按钮）收进 ··· 的底部面板，只有一份，按钮状态在开合之间保留；页面自己的"更多操作"菜单在面板里摊平。被手机布局隐藏的页头（如首页的电脑版）不加入 ···。执行页的"← 现场模式"在手机上隐藏（底部栏已有）。
- **＋**：一点打开快速记录，自动关联进行中的实验及其第一个未完成步骤（`/entries/new?mode=capture&experiment=active`）；点按时先让键盘弹出，页面切换后编辑器接过焦点（`keep-keyboard.ts`）。首页四张卡片（#117）保留不动，其中"快速记录"卡片改用与 ＋ 相同的地址。
- **手机编辑器**（`EditorSurface.tsx`）：触屏上不再显示块旁的 ⋮⋮ 和浮动气泡，改为键盘上方一条工具栏：＋插入（同 "/"）、Aa（块菜单：转换为、格式、上移下移、复制、删除）、图片、风险红、缩进 / 取消缩进、撤销 / 重做、收起键盘；选中文字时换成气泡原有的全部格式（与电脑共用 `FormattingControls`）。键盘收起时长按一个块：浮起一份副本跟随手指，蓝线指示落点，松手移动（`moveBlockTo`）；长按不动则打开该块的菜单。打字时的长按仍交给系统（放光标、选字）。电脑上不变。
- 弹出菜单按可见区域（键盘以上）定位（`protocol/popover.ts`）。
- **与 App 的桥**（`native-bridge.ts`）：执行页把本实验的计时发给 App（`NativeRunTimers`）；"其他设备 → Apple Watch"在 App 里变成"发送到手表"；侧栏顶部在 App 里显示当前服务器和"更换服务器"。浏览器里这些都不出现。
- "@ 引用"未做：LabNest 没有这项功能，Notion 工具栏里的这一项没有对应。
