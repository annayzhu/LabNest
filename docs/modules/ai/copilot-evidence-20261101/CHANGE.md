# Copilot 研究信息确认与文献失败处理

本次修复：模糊术语和研究对象先经作者确认；文献检索失败不再进入生成阶段；生成的方案可按章节预览并填入。

## 行为

- 新运行先生成方法、对象、样本、目标四个可编辑字段，停下来等待作者确认。未知内容允许明确写待定。重复推进不能绕过确认。
- 每次运行可选择 PubMed 备用来源。Europe PMC 请求失败后，本阶段改用 PubMed；不重复请求已失败的来源。所有来源失败、检索无结果、没有选出相关论文分别显示未完成。
- 全文不可读但有摘要时明确按摘要读取。没有可核对的相关原文摘录，停止生成。出处核对不等同于当前研究假设已获证实。
- 设计按目的、比较、读出、对照、证据限制呈现；材料与方法、判定标准、待确认项分别填入已有章节。引用独立预览和采纳。已有内容按原顺序保留，跨章节块 ID 唯一。
- 不添加数据迁移；旧运行和建议保持可查看、可采纳。

## 验证

先新增三个复现用例，均在旧代码失败：检索服务失败、检索为空、没有文献摘录仍生成。修复后通过。
新增备用来源授权/失败、PubMed 元数据解析、Boolean 检索式保留、摘要回退、确认阶段不可绕过、全部论文不可读、分章节填入及原文保留检查。

本次只修改研究方案 Copilot，不修改通用编辑器和附件上传流程。使用 labnest-editor-qa 的实际路由、保存回读、原内容保留及响应式检查。既有编辑器的物理设备触控、中文输入法、上传和 Word/PDF 导出未在本次重测。

PubMed 接口依据：[NCBI E-utilities 参数说明](https://www.ncbi.nlm.nih.gov/books/NBK25499/)，ESearch JSON 获取 PMID，EFetch XML 获取元数据与摘要；不将摘要宣称为全文。
