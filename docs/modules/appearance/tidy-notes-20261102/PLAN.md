## 2. 发现与待确认问题

**Q319 实验设置与样本。** 原因：这个面板放在 A4 记录里，继承了正文的宋体/Times，`text-sm` 算出来是 14 px，比记录正文（13.3 px）还大。没有样本时同时显示“使用的样本 0 · 产出的样本 0”和两句说明，信息重复。  
推荐：
- 面板改用界面字体和界面字号（13 px，说明 12 px），与同一页“执行记录”的进度行一致；打印仍用表格（S12 不变）。
- 没有样本时不显示“0 · 0”计数行，按钮左侧只写一行“还没有选择样本”（12 px、灰色）；删去第二句，按钮“选择样本…”里已有“搜索 / 粘贴编号 / 整盒”三种方式。
- 已锁定的实验没有样本时只写“未选择样本”。

**Q320 规程中的范围值。** 规程正文里每个范围值后面都跟着“待选采用值”（例如“20–30 min 待选采用值”），一步里出现两三次。  
推荐：范围值本身就说明要选，不再显示这四个字；改为虚线边框（已有的待定样式）加悬停提示和读屏文字。其他待定原因（待选体系、执行时填写、取值冲突等）照常显示。

**Q321 执行记录（列表视图）。** 每一步右侧都竖排“计时器”“计算器”两个按钮，下面是“记一笔 / 原文”和一直展开的“偏差或异常”输入框；18 步就是 18 个空输入框。标题旁还有一句未翻译的英文说明。  
推荐：
- 四个工具并成一行小按钮：计时器、计算器、记一笔、原文。
- “偏差或异常”收为“记录偏差…”文字按钮，点开原位出现输入框；已有内容时直接展开。
- 删除标题旁的说明句。

**Q322 工具页。** 页首一句英文标语；每张卡片有“Input / Output”两行英文清单；页脚一句英文说明；三张卡片的介绍没翻译。  
推荐：删除页首标语、卡片的 Input / Output 两行和页脚说明；卡片只留图标、名称、一句介绍、版本、预览和打开。三句英文介绍补中文。

**Q323 结果页的结果文件。** “Where instrument exports go”说明框、“表格数据”“原始与支持文件”下各一句说明，都是英文；上传框是浏览器自带的“Choose File / No file chosen”。  
推荐：删除说明框和两句说明，两个小标题已经说明用途；上传框改用 `FilePicker`；补齐中文。

**Q324 回收站。** 每行一个实心“恢复”和一个红色“永久删除”，15 行就是 30 个醒目按钮；页首一段英文说明。  
推荐：
- “恢复”改为普通边框按钮，“永久删除”改为红色文字按钮。
- 页首说明缩成一句中文：“恢复后保留原编号和关联；仍被其他记录引用的不能永久删除。”

**Q325 导入页（规程、库存、结果等共用的导入区）。**
- 每页都写“确认导入时，LabNest 会重新校验原始文件，并连同 SHA-256 校验值一起保存。”
- 规程导入页按钮下有一整段写法规则。
- JSON / Markdown / DOCX 三张模板卡各写一行“结构化 实验规程 输入”。

推荐：删除 SHA-256 一句和模板卡上的说明行；写法规则收进“写法说明”折叠，默认收起，Word 模板里已有同样说明。

**Q326 AI 设置与方法设计。**
- AI 设置里“开启不会处理历史记录”出现两次。
- 页面另有“作用于当前 LabNest 工作空间，与原设置范围一致；Visualization Studio 使用自己的设置。”
- 方法设计页写“方法卡由 ChatGPT · 邮箱 · 模型 归纳”，把登录邮箱显示在正文里；另有“每次外部检索与抓取都会记入活动日志”。

推荐：
- “开启不会处理历史记录”只保留页首一处。
- 删除“作用于当前工作空间…”和“记入活动日志”两句。
- 方法设计页只写模型名，不显示邮箱。AI 设置里的服务名仍带邮箱，用来区分登录账号。

**Q327 设置。**
- “即时应用”说了两次，“不改变科研图表配色”也说了两次。
- 文档字体里有“英文字符不会再沿用宋体”，这是在讲改动历史。
- 导入字体有三句说明。

推荐：
- 重复的句子各留一处，删除讲改动历史的那句。
- 字体导入的三句合成一句：“字体文件只在本浏览器使用，不上传；请只导入有使用权的字体。”

**Q328 规程详情。**
- 侧栏“来源”直接显示内部值“ai recognized”。
- 活动记录显示英文原名“Update”“Protocol Recognition Saved”。
- 材料表在桌面完整显示时，仍提示“左右滑动查看完整表格”。

推荐：
- “来源”显示“AI 识别”，活动名补中文。
- 滑动提示只在表格确实超宽时显示。

**Q329 附件页。** 说明同时写中英文（“此格式不支持在线预览，请下载后打开。 / Download this format to open it.”）。  
推荐：只显示当前界面语言。

**Q330 浏览器自带的文件选择框。** 实验侧栏“附件”和结果页仍显示“Choose File / No file chosen”，不跟随界面语言，也比周围按钮更显眼。  
推荐：可见的文件选择框统一改用 `ui/FilePicker.tsx`（DESIGN.md 已规定）。本批只改看得到的几处：
- 实验侧栏的附件；
- 结果页的数据和文件；
- 采购单；
- 样本批量表。

隐藏在按钮后面的不动。
