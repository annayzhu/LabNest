# 孔板接入主 Calculator

基线：main `d91d8203c912f1733ce72e3dc1c7fad5ff73bb72`。来源：用户指出的 Master Mix 编辑、保存方案与跨板汇总缺口。主计算器算法不重写，独立孔板产品不覆盖。

## 验收合同

1. LabNest Tools 中的孔板入口在配液抽屉中加载主 Calculator 工作台，Master Mix 使用同一组分编辑器：直接体积、浓度计算、预混/单独加入、水补足、单组/多组、预设及警告。
2. 选孔上下文在应用时重新校验；实际反应总数必须与所选孔数一致。多组按结果显示的顺序分配孔位，保存前展示映射。不得把余量计入实际孔剂量。
3. 应用结果保存为当前板的有效配液方案，包含输入、完整结果快照、结构化操作、警告、来源及汇总明细；旧方案编辑可读回完整输入。来源窗口、同源、会话及板/孔位匹配才接受消息。
4. 每板只有一个当前方案。使用独立版已有的 current/publish/stale/clear 语义；旧多方案保留一个当前项，其余保存为归档，JSON 备份保留归档。草稿、归档和需重算项不进入当前配液汇总。
5. 跨板合并兼容预混配方的基础需求，只加一次统一余量；模板/样本单独加样保留孔位来源，既不合并为预混管，也不加预混余量。
6. JSON 保存/刷新/恢复、撤销/重做、单板配液 XLSX、跨板汇总与加样清单保持一致。失效或历史计算不得写为有效结果。
7. file:// 离线孔板继续可用；LabNest 的在线/localhost 模式使用主工作台，不复制旧页面或另建计算引擎。独立产品的其他专用模块不替换。

测试边界采用用户指定的“主 Calculator 结构化结果 → 孔板应用 → 已保存方案/跨板汇总”，以及现有 WorkspaceCore 公共接口和真实 Tools 页面操作。回归算例：24 个 20 µL 反应，SYBR 10 µL、两种引物各 0.5 µL、模板单独加入 1 µL、水补足至 20 µL；10% 余量仅用于预混，预混总量 501.6 µL，模板实际用量 24 µL。再合并 12 孔同配方，共 36 孔：10% 统一余量后预混 752.4 µL，模板仍 36 µL。
