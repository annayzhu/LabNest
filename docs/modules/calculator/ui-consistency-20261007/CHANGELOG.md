# 本轮修改范围

1. 图标：完整保留附件16枚SVG原始几何，补齐各工具及操作语义，总计46枚；31个独立工具都有专属映射。统一24×24、currentColor、透明镂空；原PNG套件保留给现有外观预览/用户偏好。
2. 操作：CalculatorButton 区分主计算、次操作、管理、增加、行删除；组分/组/样本/曲线点增加按钮位于所属标题右侧。输入预设、示例、恢复、重置置于计算前；单位与数字保持紧凑同排。
3. 模式：CalculatorMode 使用真实fieldset/radio与可见选中状态；反应配液独立保留单组/多组草稿，从只有多组数据进入单组时必须选择来源组。WB保留批量草稿；其他二/三项计算模式使用分段控件，更多选项和单位继续用原生select。
4. 选择器：统一去除原生重复箭头、箭头距右12px、内容右留40px；不另造弹层。
5. 内容精简：删除反应配液“余量与组分用量”的重复说明容器；“余量只用于预混组分、未预混组分独立加入、水补足单反应体积”保留在相关字段/表旁。各工具计算依据、警告、操作差异及有效错误保留。移液设备下限、步进为真实参数，保留单层“移液设置（可选）”；非默认生效参数在收起时有紧凑摘要。
6. 展开：CalculatorDisclosure 立即显隐、方向箭头立即替换、保留挂载输入；Escape将焦点安全返回触发按钮。已有粘贴表格、预设菜单及独立孔板工具采用无动画样式/安全收起；普通系统动态设置下同样生效。
7. 草稿缺陷：额外回归修复旧主分支嵌套转染方案无法恢复的问题；明确区分显示元数据与保存的另一模式用户输入，避免空当前模式掩盖其恢复入口。

8. 非必要请求：配对溶液/反应工具的辅助链接仅在点击时导航，停止视口和悬停预加载，保留实验上下文；增加零预加载请求及真实往返测试。首次 WebKit CI 异常的底层根因没有独立证实，不过滤页面错误。

## 共用关系

主工具页、Run和LabNest孔板嵌入均使用 CalculatorWorkbench。FreePlate另有6个界面适配器，继续使用同一个打包计算引擎；接入同一生成SVG映射和几何参数，并同步版本查询串。它的非计算器孔板布局功能不在本轮重写。Tools/Today入口也接入新图标及当前计算器路由。

未改变计算引擎、单位算法、移液检查、正式导出或实验记录的数据系统；11个科学计算/输出核心文件与基线逐字节一致（见evidence/math-source-hashes.json）。
