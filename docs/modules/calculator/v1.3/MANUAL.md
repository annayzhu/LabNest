1. 先按 HTTPS.md 启用受信任的内网入口。存在证书警告或 HTTP 时，不判定离线缓存通过。
2. 打开计算器，确认六项常用入口为 3×2；进入稀释工具，输入 10 mM、10 µM、2 mL。软键盘弹出时仍能完整读取当前数值和单位并切换字段；收起后计算得到母液 2 µL、稀释液 1998 µL。
3. 复制到手机备忘录，核对数值、单位、来源和警告。若出现手动面板，实际全选并复制粘贴；记录走的是哪个分支。
4. 在浏览器原生设置中分别使用 100% 和最高 160%（无精确160%档位时记录实际最高不超过160%的档位，不冒充160%）。检查长标题、批量表格末行/末列、复制/返回/帮助及全部常用入口均可读可点。
5. Run 选第二步，填一条未提交备注和未提交参数，启动计时器。Run→计算器主页→工具→主页→Run，核对原步骤、输入和计时持续。
