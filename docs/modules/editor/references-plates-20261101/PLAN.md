## 2. 现状

**"/" 菜单**
- 写作编辑器（`WritingCommandMenu`）用于 Entry、实验记录、结果、研究计划、报告。
  - 分组：基本块、列表、插入（图片、文件、表格，以及指标、提示、数据集）、时间戳。
  - 没有样本、库存、板布局。
- Protocol 编辑器（`protocol/InsertMenu`）：
  - 已有"库存物料"：选一个库存批次，带用量，实验完成时扣减（`materialRef.inventoryItemId`）；
  - "嵌入工具"默认放入自由板布局规划器。它嵌入的是工具本身，不是一张板。
- 结果模板说明（Protocol 里的小编辑器 `ProtocolRichTextEditor`）也用写作菜单。

**样本**
- `findSamples`（`src/app/samples/actions.ts`）按编号、名称、来源搜索，可按类型、位置、在库筛选，最多 200 条。
- 实验样本区的"选择样本…"用的就是它。

**库存**
- 层级：产品（目录条目或自制设计）→ 批次（批号、位置、数量、有效期）→ 容器。
- 页面：产品页 `/inventory/products/[id]`，批次页 `/inventory/[id]`。
- Protocol 的"库存物料"一次预载最多 500 个在用批次。

**板布局**
- 工具页的自由板布局规划器是外部产品的发布副本（`public/tools/free-plate-layout/release.json`，提交 bb07fd22），LabNest 只加了桥接脚本。
  - 数据只存在浏览器 IndexedDB，一次一个项目；
  - 与外界交换靠 JSON 备份。
- 实验样本区的"板布局…"：
  - 打开 qPCR / CNV 规划器，带入本实验样本；
  - 把规划器的备份（JSON、SVG 或图片）作为实验附件上传（`linkType: plate_layout`）；
  - `PlateLayoutView` 把自由规划器的 JSON 备份画成只读网格；
  - 样本旁按名称显示所在孔（S14），现场准备清单列出这些附件。
- 文档正文里放不进一张板。

**正文怎么存、怎么显示**
- Entry 正文和科研文档的文字块都是 LabNest Markdown。
  - 图片和文件是 `documentMedia` 节点：科研文档里是 `media` 块，Markdown 里是 `<!--labnest-media:…-->`。
  - 表格在 Markdown 里是一行 `<!--labnest-table:…-->`。
- 科研文档的结构校验不认识某个块类型时，整篇文档读成空白（`normalizeScientificDocument` 校验失败即返回空文档）。
- 链接只认 http(s)：
  - 编辑器读写 Markdown 时（`scientific-tiptap.ts` 的 `inlineMarkdownToTiptap` / `inlineTiptapToMarkdown`），站内链接（如 `/samples/…`）读进来是普通文字，链接写不回去；
  - 只读显示 `EntryContentView` 把它原样显示成 Markdown 文字；
  - 搜索文字（`plainTextFromEntryMarkdown`）也只去掉 http(s) 链接的语法。

**数据量（2026-11-01）**
- 正式库：0 个样本，1 个产品，1 个批次，0 个板布局附件，0 个 Protocol 嵌入工具。
- 测试库 `labnest_inventory_20261030`：28 个产品，19 个批次，141 条 Entry，8 个实验，0 个样本。

## 3. 问题与推荐

**Q248 哪些编辑器加这三项。** 推荐：
- Entry、实验记录、结果、研究计划、报告：在"/"和 ＋ 菜单里都加"样本""库存物品""板布局"。
  - 新分组"引用"放样本和库存物品；"板布局"放在"插入"组，表格后面。
  - 拼音和英文都能搜：yb / yangben / sample，kc / kucun / wupin / reagent，bbj / banbuju / plate / 96。
- Protocol 编辑器不加：
  - 库存已有"库存物料"（带用量、完成时扣减），不再加第二个库存入口；
  - 样本属于某一次实验，不放进可重复使用的 Protocol；
  - 板布局这一批不进 Protocol（见第 5 节）。
- 结果模板说明（Protocol 内的小编辑器）也不加。

备选：Protocol 也加"板布局"，作为模板随实验快照带入。

**Q249 "/样本" 插入什么。** 推荐：
- 在光标处插入一个样本引用，像 Notion 的"提及"：
  - 样子是带试管图标的小标签，文字为"编号 名称"，例如"S-0012 HeLa RNA"。名称与编号相同时只写编号。
  - 整个标签是一个单元：退格一次删掉，不能逐字改。
  - 编辑时，悬停（手机上轻点）出卡片：类型、位置和孔位、余量、状态、来源，以及"打开样本"。
  - 只读页上，点击打开样本页。
- 存成 Markdown 链接 `[S-0012 HeLa RNA](/samples/<id>)`。
  - 不改数据库，也不改文档结构；
  - 回滚到旧版本时显示成这串 Markdown 原文，内容不丢。
- 只是引用：
  - 不把样本加进实验的"使用样本"，不扣样本量；
  - 正式的使用和产出样本仍在实验样本区选（见 Q254）。
- 表格单元格里也能插入。

备选：在实验记录里插入时，同时把样本加进本实验的"使用样本"。

**Q250 "/库存物品" 选到哪一层。** 推荐：产品或具体批次，由选的那一行决定。
- 搜索结果按产品列出：名称、品牌 · 货号、在用批次的合计余量。
- 产品下面列出它的在用批次：批号、位置、余量、有效期。
- 选产品行，插入"TRIzol"，指这个产品。
- 选批次行，插入"TRIzol · 批号 2311A"，指实际用的那一批。没有批号时写位置。
- 标签带包装盒图标；悬停卡片显示品牌、货号、位置、余量、有效期、状态；点击打开产品页或批次页。
- 列出哪些：
  - 所有启用的产品，包括还没有批次的自制设计（引物、siRNA）；
  - 停用和已归档的产品、批次不列出；
  - 已用完的批次列出，标"已用完"。
- 只是引用：不扣库存，不记用量。用量仍在实验的"用量"里记。

备选：只能选批次（与"库存物料"一致）；或只能选产品。

**Q253 样本页和库存页显示"在哪些记录里提到"。** 推荐：

备选：不提示。

**Q255 板布局用哪种编辑器。** 推荐：LabNest 文档里自带的板布局块，不嵌入现有规划器。
- 原因：
  - 规划器是外部产品的发布副本；
  - 它的数据存在浏览器里，一次只有一个项目，嵌进文档会覆盖用户在工具页的项目；
  - 要改这一点，得改外部产品。
- 板布局块的数据格式与规划器的项目备份一致：板型、参数、各孔的值、着色参数。所以可以：
  - "从规划器导入"：选规划器导出的 JSON 备份；多块板就插入多个板布局块；
  - "下载为规划器备份"：在规划器里恢复后继续做配液计算。
- 配液计算、跨板汇总、XLSX 仍在规划器里做，文档里不重复。

备选："文档模式"的规划器：在对话框里打开完整规划器，完成后存回文档。需要改外部产品，并解决浏览器存储冲突。

**Q256 板布局块能做什么（第一版）。** 推荐：
- 板型：6、12、24、48、96、384 孔。48 孔规划器不支持，"下载为规划器备份"时提示。
- 参数：
  - 默认两个："样本"和"处理"；
  - 可改名、加单位、增删，最多 6 个；
  - 选一个参数着色。
- 选孔：单击、拖动框选、Shift 连选；点行号或列号选整行或整列；全选；清除。
- 赋值：
  - 选中孔后，在侧栏给每个参数填值，或清空；
  - "样本"参数可以从样本库选（同一个选择器），存的是样本引用。
- 依次填入：
  - 名单来源：本实验的使用样本（按分组顺序）、在样本选择器里多选的样本，或粘贴一列；
  - 填入选中的孔，按 N（逐列，规划器默认）或 Z（逐行）；
  - 每个名称重复 1–4 孔；
  - 孔不够时提示，只填得下的部分。
- 显示：
  - 板名、"96 孔 · 按 样本 着色"、网格、图例（每个值几个孔）；
  - 颜色按值依次分配，不重复；
  - 空孔为白。
- 编辑方式：
  - 正文里显示只读网格和"编辑"按钮；
  - 点"编辑"打开大对话框（手机上全屏），改完点"完成"写回，"取消"放弃；
  - 对话框里可以撤销；
  - 换成更小的板型会丢掉板外的孔，先确认；
  - 不在正文里直接拖选孔，以免和正文的选中、块拖动冲突。
- 一个块是一块板，块上可以写说明。
- 光标在表格里时，"/"菜单不显示"板布局"。

备选：每孔只有一个标签（不分参数）；或直接在正文里编辑网格。

## 6. 实现计划（按推荐）

**存储**
- 不改数据库，不加文档块类型。
- 引用是 Markdown 链接，板布局是 Markdown 里的一行 `<!--labnest-plate:…-->`，与表格相同。Entry 和科研文档都这样存。
- 不加新块类型的原因：科研文档的结构校验不认识的块类型会让整篇文档读成空白，回滚到旧版本时尤其危险。存在文字里，旧版本只会显示成一行标记文字，内容不丢。

**引用（Q248–Q252）**
- `src/lib/record-references.ts`：识别和生成三种链接 `/samples/<id>`、`/inventory/products/<id>`、`/inventory/<id>`；从 Markdown 里找出所有引用。
- TipTap 行内节点 `recordReference`（kind、id、label）：标签样式、悬停卡片。
- `scientific-tiptap.ts`：`inlineMarkdownToTiptap` 把这三种链接读成节点，`inlineTiptapToMarkdown` 把节点写回链接。其他站内链接照旧。
- 选择器 `ReferencePicker.tsx`：
  - 样本用 `findSamples`，加上实验优先、最多 50 条、按最近修改排序；
  - 库存新加 `findInventoryReferences`（产品和在用批次）；
  - 悬停卡片读只读接口 `GET /api/references/<kind>/<id>`。
- `WritingCommandMenu`：新分组"引用"，"插入"里加"板布局"；新参数 `references`，Entry 和科研文档打开，结果模板说明不开。
- 只读和搜索：`EntryContentView`、`TiptapCellContentView` 把引用画成标签；`plainTextFromEntryMarkdown` 和实验的 `searchText` 只留文字。

**板布局（Q255、Q256）**
- `src/lib/plate-layout.ts`：
  - 块的格式（zod）、板型、孔号；
  - 选择（框选、连选、整行整列）和依次填入（N/Z、重复）；
  - 规划器备份的导入导出（`parsePlateLayouts` 移到这里）；
  - Markdown 标记、搜索文字、打印表格。标记里的内容整体转义，连 `*`、`~`、括号也转，旧版本的 Markdown 解析碰不到它。
- 共用节点 `documentPlate`，做法同 `documentMedia`。
- 组件：
  - `PlateLayoutGrid`：只读网格，`PlateLayoutView` 也改用它；
  - `DocumentPlateNode`：正文里的块；
  - `PlateLayoutEditor`：编辑对话框。

**反向列表与实验（Q253、Q254、Q257）**
- `src/lib/record-mentions.server.ts`：在 Entry、实验、结果、研究计划、报告的正文里查 ID（参数化 SQL，只读）。
- 样本页、产品页、批次页加"记录中提到"。
- `ExperimentSamples`：未加入样本的提示；去掉上传；S14 改读记录里的板布局。`run-preparation.ts` 同样改读。

  - 选孔、依次填入；

  - 搜索文字；
  - 中英文文案。

## 8. 实现（2026-11-01，按推荐）

**存储**：与第 6 节相同。引用是 `[标签](/samples/<id>)`、`[标签](/inventory/products/<id>)`、`[标签](/inventory/<id>)`；板布局是一行 `<!--labnest-plate:…-->`。没有数据库迁移，没有新的文档块类型。

**引用（Q248–Q252）**
- `src/lib/record-references.ts`：链接的识别、生成与标签文字；`/inventory/list` 等页面不算批次。
- `src/components/RecordReference.tsx`：行内节点 `recordReference`（整体一个单元，不带格式）、标签、悬停卡片（编辑时悬停或选中、只读页悬停或聚焦）、只读页的链接。
- `src/components/useRecordReferenceDetails.ts`：一页上所有标签合成一次请求 `GET /api/references?refs=…`，一分钟内复用；读不到（离线）时不算删除。
- `src/components/ReferencePicker.tsx` + `GET /api/references/search`（`src/lib/record-references.server.ts`）：本实验样本在前（使用的在前，按分组、再按实验顺序），其他按最近修改；库存按产品列出、批次在下，没有产品的旧库存单列；最多 50 条；手机为底部弹层。
- `WritingCommandMenu`：新分组“引用”（样本、库存物品），“插入”里加“板布局”（在表格里不显示）。Entry（`MarkdownRichTextEditor`）和四种科研文档打开，结果模板说明不开。实验编辑页和 Entry 用 `ReferenceScope` 告诉选择器是哪个实验。
- `scientific-tiptap.ts`、`tiptap-table-serialization.ts`：链接 ↔ 节点；带标签的标题按 Markdown 保存；表格单元格的纯文字保留链接。
- `EntryContentView`、`TiptapCellContentView`：只读页画成标签。`plainTextFromEntryMarkdown`、`documentPlainText` 只留标签文字。
- `editor-slash.ts`：紧跟在标签后输入“/”也打开菜单（标签像空格一样结束一个词）。

**板布局（Q255、Q256）**
- `src/lib/plate-layout.ts`：格式、孔号、框选、Shift 连选、整行整列、依次填入、换板型、图例、Markdown 行、搜索文字、打印表格、规划器备份导入导出。
- `PlateLayoutGrid`（共用网格）、`DocumentPlateNode`（正文中的块）、`PlateLayoutEditor`（编辑对话框，按需加载）。
- 对话框是固定定位的遮罩层，不用原生模态 `<dialog>`：否则其中打开的样本选择器和确认框会落在它下面。
- 换板型时，名字还是默认名（如“96 孔板”）的板跟着改名。
- 在计划之外加的两处显示细节：
  - 48 孔及以上的板，孔里写图例编号（1、2、3…），图例用同样的编号；6–24 孔板写值本身。96 孔板放不下“RNA-0001 KYSE150 NC RNA”这样的名字。
  - 板的颜色用自己的属性 `data-plate-tone`：Protocol 的样式给 `[data-tone]` 定了 5 种暗色，加载顺序不同时会盖掉板的颜色。

**反向列表与实验（Q253、Q254、Q257）**
- `src/lib/record-mentions.server.ts`：参数化 SQL，在五类记录的 `contentJson` 里找 ID，只读。样本页、产品页（含其批次）、批次页加“记录中提到”。
- 实验页：`documentPlateLayouts`、`documentSampleIds` 读记录正文；样本区显示“记录里提到、尚未加入的样本”，一键用 `addExperimentSamples` 加入。
- 样本区“排板…”：去掉上传；S14 读记录里的板（按样本 ID），以前上传的附件照旧解析；现场准备清单（`run-preparation.ts`、`RunSystemPreparation`、`RunPageMenu`）列出记录里的板。
- `PlateLayoutView`（旧附件）改用共用的解析和网格，原来的 `parsePlateLayouts` 删除。
- Q257 核对结果：qPCR 和 CNV 规划器都只导出 Excel，没有 JSON 项目备份，所以“导入备份”只支持自由板布局规划器。排板面板的说明改为：它们导出的 Excel 用“/附件”放进记录。

**中文**：`src/lib/i18n-references.ts`（先于主词典展开）。“References”（参考资料）、“Used”（用量）、“Discard”（弃置）已有别的意思，这里分别用 “Link a record”（引用）、“Used here”（本实验使用）、“Discard changes”（放弃修改）。
