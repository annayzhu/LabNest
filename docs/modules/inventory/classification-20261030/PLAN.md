## 1. 已确认的决定

### 1.1 分类（Q136–Q146）

**Q136 大类**：系统预置 5 个，按生命周期划分：试剂与化学品、耗材、生物材料、样本、仪器与器具。可以改名、隐藏，不能新增或删除。

**Q137 类型表**：沿用 `ScientificSchemaDefinition` 作为唯一的类型表，增加“所属大类”，`entityType` 改为可空。库存先接入；实体类型和样本类型以后再迁移。不另建第四套分类。

**Q138 旧分类迁移**：

| 旧值 | 大类 / 类型 |
|---|---|
| reagent | 试剂与化学品（未细分） |
| consumable | 耗材（未细分） |
| antibody | 试剂与化学品 / 抗体 |
| kit | 试剂与化学品 / 试剂盒 |
| chemical | 试剂与化学品 / 化学品 |
| instrument_accessory | 仪器与器具 / 配件 |
| biological_sample、other、空值、导入时不认识的值 | 待归类，由人确认 |

**Q139 类型带什么**：首批只带字段模板、默认管理方式、默认单位、是否记录批号和有效期。冻融、传代、分装、质检以后再加；功能上线前不显示开关。

**Q140 产品层**：在类型和库存批次之间加一层“产品”。
- 买来的：按品牌 + 货号，每个货号一个产品。
- 自制的：对应序列库或实体条目。
- 类型、说明书、SDS、试剂盒组分清单、管控等级挂在产品上。
- 安全库存按产品计算，把各批次余量加起来。

**Q141 新建类型的门槛**：
- 只能在“类型”页新建；物品和产品表单里只能选择。没有合适类型就留“未细分”。
- 新建时列出名称相近或字段重合的已有类型。
- 支持合并和停用。
- 预置一套默认类型。
- 等有了账号角色，再限制为只有管理员能建。

**Q142 大类调整**：
- “试剂”改名为“试剂与化学品”。化学品、引物、siRNA、气体归这里；质粒归生物材料。
- 低库存提示按大类区分：试剂与化学品和耗材提示采购；生物材料提示重新扩增；样本只提示剩余数量。

**Q143 管控等级**：系统固定的多选列表，不做成类型。剧毒、易制毒类强制精确登记，并要求上传 SDS。

**Q144 试剂盒**：
- 按盒管理，每盒带组分清单。
- 组分只记有 / 用完 / 缺失。
- 任何一个组分不能用，整盒标为“不完整”。

**Q145 说明书**：挂到产品上，分产品说明书、SDS、试剂盒手册三种。试剂盒手册走现有识别流程生成 Protocol。

**Q146 气体和余量单位**：
- 气体按钢瓶管理，读压力表登记余量。
- “登记余量”的单位增加反应数、MPa 和百分比。
- 增加“退瓶”操作。

### 1.2 本批追加（Q147–Q150，2026-10-30 用户选择推荐项）

**Q147 测试边界**：
- A 纯规则函数：旧分类映射、按产品合计的安全库存、按大类的低库存提示、管控等级规则、试剂盒完整性、删除阻止条件、相近类型、余量单位。
- B 服务端操作（模拟数据库，沿用 `actions.test.ts` 写法）：产品身份同步到各批次、类型合并迁移产品、退瓶与新单位、有流水时拒绝删除、流水撤销。
- C 在正式库的只读克隆上运行迁移并核对数量，再在 3002 浏览器里逐项操作新增、编辑、删除。

**Q148 产品页面**：单独的产品列表页和详情页。详情页集中放各批次、说明书/SDS、试剂盒组分、管控等级和安全库存；库存物品页只放这一批的信息，并链接到产品。

**Q149 删除库存物品**：与库位一致。没有流水、实验用量和采购入库的物品，输入名称确认后永久删除；否则只能归档。归档后台账保留，可以恢复。

**Q150 流水更正**：原记录不改不删。“撤销”补一条数量相反的更正记录，两条互相标注，余额随之恢复。

## 4. 界面：紧凑、对齐

依据 DESIGN.md 的 Collection Toolbars、Page Actions、Side Panels 和 Few Questions per Panel。

- **列表页**：
  - 统一工具栏：搜索、筛选（大类、类型、负责人、位置、库存状态、状态）、排序、条数、导入/导出、新建。

  - 标题行只放编辑和 ⋯（采购、归档/恢复、删除）。
