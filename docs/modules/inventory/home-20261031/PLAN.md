## 1. 已确认的决定

| 问题 | 决定 |
|---|---|
| Q179 位置和导航 | “库存”先到主页；全部批次的表格改名“库存清单”，在 `/inventory/list`。带筛选的旧链接（`/inventory?flag=low` 等）转到清单并保留筛选。顶部一排标签：主页 · 库存清单 · 产品 · 类型 · 库位，带图标和数量；批次页、产品页也显示，并亮起所属的一个（Q174）。详情页标题上方的“← 返回”回到进来的地方：主页，或带着原搜索和筛选的清单 / 产品列表（Q173） |
| Q180 搜索 | 主页最上面一个大搜索框，桌面上打开即可输入；边打边出结果，最多 8 行；搜名称、英文名、品牌、货号、批号、条码、分装编号、CAS、PI、库位（含上级库位）；每行一个产品，显示总库存、库位、最近有效期、提醒；回车打开第一行，方向键选择；旁边“扫码”，条码只对应一个批次时直接打开 |
| Q181 快速出入库 | 每行“领用”“入库”在原地展开；多个批次时默认选条码命中的或最早过期的一批，可改；精确用量填数量（按 Q172 的单位位数）、经手人、说明（受控物品必填）；按实物管理的领用是取出 N 个实物、入库是添加实物；页头有“登记库存”“导入” |
| Q182 分类 | 按大类列出类型及数量，点开是按这个类型（或大类）筛选的库存清单（只看启用的批次）；类型按数量排序，隐藏和空的大类不显示；不做置顶 |
| Q183 提醒和最近 | 一排提醒：库存不足、已用完、已过期、30 天内过期、使用中、缺 SDS、疑似重复、待处理采购，点开是筛选好的清单；清单页顶部的提醒移到主页，清单保留为筛选条件（新增“使用中”）；没有搜索时列出最近用过的库存 |
| Q184 手机 | 同一页面：搜索和扫码在最上面，然后是提醒、最近用过（带领用 / 入库），分类折叠在最后；库存清单在手机上仍是原来的实验台视图（标题改为“库存清单”） |
| Q188 顺序 | 先做主页，再做序列并入；两批分开发布 |

说明：
- 分类旁的数字是这个类型在用的批次数，与点开后的清单一致（建议里写的是“产品数量”）。
- 标签的选中样式按 DESIGN.md 的 Active Label Rule：主色文字、底部细线和浅底色，不用整块填色。
