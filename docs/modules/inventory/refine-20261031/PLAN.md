# 库存：手机入口、改名与编辑合一、产品页精简、流水、领用后用完、整体 UI

日期：2026-10-31
前一批：[序列并入产品（Q185–Q187）](../sequence-merge-20261031/PLAN.md)，已随样本模块发布（`19ad19a3`）。
状态：用户回复“按推荐”。Q189–Q197 已实现，待 3002 验收；Q198 等这一批发布后再做；Q200 已由 `6d04f8dc` 的开发服务守卫覆盖。样本模块另在自己的会话和分支里做，问题编号从 S1 起，不在本批。

## 1. 用户反馈（2026-10-31）

1. 手机上打开库存时，底部的“新建”容易被当成新建库存。
2. 手机库存主页要加快捷入口：登记库存（自己填，或拍照、选照片识别）和领用。
3. 物品建好后要能改名，之前的入库和领用记录跟着变。
4. 从库存清单点进去能改的内容，和从产品点进去能改的内容不一样，需要整合。
5. 产品详情里的“批次”格和下面的批次表重复，界面要更简洁。
6. 点击已有库位时，显示这个位置现在存放的清单。
7. 流水的说明里不要显示实物编码。
8. 领用后不强制在实验里用掉，用户可以自己标记是否用完。
9. 导入页的几个标签要做得更显眼。
10. 整体 UI 有点土，要改得高级一些。

## 2. 现状

**手机底部“新建”**
- `MobileBottomNav` 里的“新建”实际是“新建快速记录”，打开 `/entries/new?mode=capture`。
- 中文界面只显示“新建”两个字。

**改名**
- 产品改名后，`syncProductLots` 会把新名字写进它的全部批次。流水按批次关联，所以也会跟着变。
- 批次编辑页没有名称框，只有“选择产品”，所以从库存清单进去改不了名。
- 实验用料记录（`RunMaterialUse.name`）存的是当时的名字，不会跟着变。

**两套编辑表单**
- 批次编辑（`InventoryItemForm`）管：批号、数量、库位、位置、有效期、供应商、PI、储存条件、容器、条码、分装编号和备注。
- 产品编辑（`InventoryProductForm`）管：名称、英文名、品牌、货号、CAS、类型和类型字段、序列、管控等级、生物安全、安全库存和备注。
- 两边的字段不重叠，也没有互相跳转的入口。

**产品详情**
- 标题下有“库存 / 批次 / 类型 / 提示”四格，四格下面是批次表。
- 没有批号的批次，在表里显示产品名，与标题重复。
- 右栏的品牌和货号，与标题上方的重复。
- 类型字段为空时，也单独占一节。
- 文档上传露出浏览器自带的“Choose File”。

**库位**
- 库位列表不能点击。
- 库存清单按库位筛选时只看这个库位本身，不包括下级库位。

**流水**
- 实物领用记成“转移 −1”，说明是 `Container <id>: issue; physical movement…`。实物没有编号时，这里显示的是数据库 ID。
- 经手人为空，领用人只记在实物上。
- 编辑时改位置，会记一条“转移 0”。
- 时间用 `toISOString()` 生成，显示的是 UTC（北京时间 19:33 显示成 11:33），而且用的是等宽字体。

**领用后用完**
- 实物已有“用完”（`empty`）动作，但只在批次页的实物列表里。在主页或手机上领用之后找不到它。
- 实验执行页记录用量时，要求实物处于“领用中”。不记录用量也可以。

**导入页标签**
- 来源标签是 13px 的文字加下划线，和库存顶部的图标标签不一致。

## 3. 问题与推荐

**Q189 手机底部“新建”**
- 改名为“速记”，图标换成笔，功能不变（打开快速记录）。
- 这个按钮不随页面变化。

**Q190 手机库存快捷入口**
- 手机主页搜索框上方放两个大按钮：“登记库存”和“领用”。
- “登记库存”弹出三项：自己填、拍照识别、从相册选。
  - 后两项直接调起相机或相册，选好后进入 AI 识别入库的核对页，照片直接带过去，不用再选一次。
  - AI 未就绪时，这两项按 DESIGN.md 变灰，点开是 AI 设置引导。
- “领用”进入领用模式：搜索或扫码，点一行就直接展开领用表。

**Q191 改名**
- 产品名是唯一的来源。在产品编辑页或批次编辑页改名后，所有批次、流水、领用记录和实验用料记录都显示新名字。
- 实验用料记录在名字旁保留一行小字“记录时为 旧名”，便于追溯。历史记录里的原文不改。

**Q192 两套编辑合成一套**
- 批次编辑页分两段：
  - 上段“产品”：字段与产品编辑页相同，保存后作用于这个产品的全部批次，旁边写明“会同时改到 N 个批次”。
  - 下段“这一批”。
- 产品编辑页只有“产品”一段。
- 把批次挂到别的产品，改为次要操作“移到另一个产品…”。

**Q193 产品详情精简**
- 去掉四格。标题下用一行写类型、大类、合计库存和批次数，例如“组织芯片TMA · 生物材料 · 共 2 盒 · 1 个批次”。有需要处理的事时才出现提示。
- 批次表里没有批号的批次，显示“未填批号 · 10-29 登记”。
- “提示”列有内容时才出现。
- 右栏去掉品牌和货号。空的类型字段不再单独成节，改成“补充信息”链接。管控等级为普通时不显示。
- 文档上传换成正式的按钮。

**Q194 库位**
- 库位名可以点击，打开库存清单，筛选为这个库位及其下级库位里在用的批次。
- 清单顶部显示库位路径和温度，可以一键清除筛选。

**Q195 流水**
- 说明里不再出现实物编码。旧记录在显示时去掉，不改数据库。
- 实物领用显示为“领用”，经手人是领用人，说明写“放到 16F·海尔4℃冰箱”。归还和用完同样处理。
- 编辑时改位置显示为“移位”，变更列显示“—”。
- 整个库存模块的时间都按北京时间显示，用普通字体的等宽数字。
- 整列都为空的列不显示。

**Q196 领用后自己标记用完**
- 领用表加一个“已用完”选项，默认不勾。
- 主页新增“领用中”：按领用人列出在外的实物，每件有“用完”“归还”“转交”三个按钮。提醒里的“使用中”点开就是这里。
- 批次页保留同样的按钮。
- 实验里照样可以记录用量，但不是必须的。

**Q197 导入页标签**
- 改成和库存顶部一样的图标标签：表格、发票/送货单/标签、粘贴文字、序列。
- 字号 14px；选中项用主色文字，加底线和浅底色。
- 标签下面用一行说明这个来源能做什么。

**Q198 整体 UI**

从共享样式层改，全站一起变，不逐页打补丁：
1. 页面上只留一层容器。去掉卡片套卡片和统计格，区块之间用留白和标题分隔。
2. 表格表头不铺灰底，用 12px 浅色字；行与行之间用细线；数字右对齐；空列不显示。
3. 日期和数量改用普通字体的等宽数字，等宽字体只留给货号、条码、CAS 和序列。区块标题用 14px 半粗，页面标题用 20px。
4. 数量变化不再用粗体的红色和绿色。
5. 文件上传、下拉框和输入框统一高度和样式。

做法：先改共享组件（DataTable、Panel、PageHeader、按钮、表单、标签页）和库存各页，再在实验、方案、首页各截一组前后对比图，同时更新 DESIGN.md。
