## 1. 用户反馈（2026-11-01）

有些库存用完了没关系，可以不用报警。

## 2. 现状

提醒在每次打开页面时现算，不存进数据库，也没有任何开关能关掉。

**低库存**
- 只有填了安全库存的产品才报。
- 按产品所有在用、已记数量的批次合计来比（`productStock`），单位不同的批次不算进去。

**缺货**
- 没有任何条件：任何一个批次数量到 0 就报（`getInventoryRiskFlags`）。
- 这个批次一直保持“在用”，一直报，直到有人手动归档。
- 同一产品的另一批还有货，用完的那一批照样报缺货。
- “按容器”管理时，数量只数仓库里的瓶子。瓶子都领出去还没用完，数量就是 0，也算缺货。

**其他**
- 首页“需要关注”数的是批次。一个低库存产品有 3 个批次，记成 3。
- 数量为 0 的批次照样报“已过期”和“即将过期”。
- 停用或归档的产品，名下还在用的批次照样报。

## 3. 问题与决定

**Q237 谁会报警**
- 只有填了安全库存的产品，才有“低库存”和“缺货”提醒。
- 没填的产品，用完了只显示中性的“已用完”，不进“需要关注”。
- 安全库存填 0，表示“用完时提醒我”。
- 不加新开关，用的还是“安全库存”这一项。

**Q238 按产品算**
- 产品所有在用批次合计为 0 时报“缺货”，合计不超过安全库存时报“低库存”。
- 一个批次用完而别的批次还有货，不算问题。
- 首页“低库存”和“缺货”数的是产品。“已过期”和“即将过期”仍按批次数，因为每批的有效期不同。

**Q239 用完的批次**
- 数量已记录且为 0 的批次显示中性的“已用完”标签。
- 库存清单默认不列出已用完的批次，筛选“含已用完”时才列出。
- 不自动归档，流水全部保留。
- “按容器”管理时：
  - 还有瓶子在领用中，就不算用完；
  - 领用中的瓶子也算进产品合计，所以最后一瓶领出去还没用完时不报缺货。

**Q240 过期提醒**：已用完的批次不再报“已过期”和“即将过期”。

**Q241 在哪里设置**
- 产品编辑页把“安全库存”写成“库存提醒”，三个选项：
  - 不提醒（不填）；
  - 用完时提醒（0）；
  - 低于 X 时提醒（X 和单位）。
- 产品清单的批量操作里可以一次给多个产品设置。
- 已停用或已归档的产品永远不提醒。

**Q242 现有数据**
- 已经填了安全库存的产品照旧提醒。
- 没填的产品，“缺货”会从首页消失。
- 上线前列出正式库里“现在报缺货、但没填安全库存”的产品，由用户挑出真正需要补货的，批量设成“用完时提醒”。

## 4. 实现（2026-11-01）

**规则**：`src/lib/inventory.ts`
- 状态里新增中性的 `used_up`（已用完）：数量已记录、手上什么都不剩的批次。
  - “按容器”管理时，领用中的瓶子也算还在手上（`stockOnHand`、`heldCount`）。
  - 已用完的批次不再报“已过期”和“即将过期”（Q240）。
- 缺货和低库存是产品的状态（`productSafetyStock` 返回 `low` 和 `depleted`），只在以下情况下才报：
  - 产品填了安全库存；
  - 产品是在用状态。
- 缺货的意思是：产品所有在用、已记数量的批次，在任何单位下都什么都不剩。所以安全库存填 0（用完时提醒）不需要单位。
- 低库存仍按安全库存的单位合计来比。
- 没有产品的旧批次照旧用它自己的阈值，规则相同。

**页面**
- 首页“需要关注”：低库存和缺货数的是产品，点开是产品清单的对应筛选；过期仍按批次数。
- 库存清单：
  - 在用且已用完的批次默认不列出，表格下面写“另有 N 个已用完的批次没有列出。显示”。
  - 状态筛选新增“已用完的批次”，手机上同样处理。
- 徽标：“已用完”是灰色，“缺货”是红色。
- 产品清单：新增“缺货”筛选和徽标。
- 产品页：缺货时显示“缺货”和补货建议。
- 批次页、库存清单和产品合并页：安全库存为 0 时写“用完时提醒”。
- 首页搜索行：
  - 只有全部批次都用完时，这一行才显示“已用完”；
  - 低库存和缺货跟着产品走。

**设置**
- 产品表单（也是批次编辑页上段）的“安全库存”改成“库存提醒”，三个选项：
  - 不提醒；
  - 用完时提醒（存 0）；
  - 降到一定数量时提醒（数量和单位）。
- 产品清单的批量操作新增“库存提醒…”，只有“用完时提醒”和“不提醒”两个选项，不涉及单位。
  - 已经是所选设置的产品会跳过，并写明原因。
  - 改成“用完时提醒”时保留原来的单位。

**中文**：在 `i18n-inventory.ts` 末尾加了一段，也让“out of stock / Out of stock”统一译为“缺货”。原来分别译成“已用完”和“库存耗尽”。

**测试**
- 改了原来 3 处断言：没填安全库存时，数量为 0 的批次只算“已用完”，不再算缺货。
- 新增的测试覆盖：
  - 已用完时不再报过期；
  - 安全库存为 0 时，任何单位都还有货就不报缺货；
  - 领用中的瓶子算作库存；
  - 停用或归档的产品不提醒；
  - 首页搜索行的“已用完”；
  - 批量设置时跳过已有相同设置的产品。
- 全部单元测试 1717 项通过，`tsc` 和 eslint 无错误。
