## 问题与最小修复

右侧孔位信息的内容高度参与了整行高度计算；名称换行时，孔板行和下方配液区随之变化。复现脚本在 1366×768 记录到孔板行高度波动 320.34 px。

- 桌面信息栏不再用内容高度撑开孔板行，在孔板现有高度内独立滚动。
- 为标签和常见的四行详情预留 98.22 px；详情正文仍为 13 px，标签为 12 px。更长的名称完整换行，不省略、不裁切文字。
- 悬停信息经过孔间空隙、右侧留白、进入信息栏以及滚动时继续保留；离开整个板区时再清空。
- 1024 px 以下保留原来的上下排布，不套用桌面尺寸约束。新增 CSS 仅作用于屏幕。

维护源码只改 `app/globals.css` 与 `app/PlateViewport.tsx`；本次独立差异见 `hover.patch`。整合前一次自由孔改动的完整补丁仍由发布清单中的 `sourcePatch` 指向。
