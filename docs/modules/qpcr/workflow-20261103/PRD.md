用途 产品设计 开发拆分 联调与验收

## 1 产品目标与核心决策

用户在同一个实验中完成计划、排板、配液、结果分析、图表整理和记录打印。工具从当前任务的位置打开，已有信息自动带入，完成后把可查看、可继续编辑、可打印的产出保存回原记录。

本次改造以真实操作顺序组织界面：先输入样本与基因，再查看整板，随后配液；实验完成后，从结果记录进入分析，处理需要复核的孔，整理图表，再回到记录补充结论并打印。

**界面优先呈现当前任务所需的信息。** 常规规则、计算依据、版本和详细操作记录放入详情或后台保存；只有影响当前操作的具体问题才在工作区出现。正常流程不设置反复确认或常驻说明横幅。

### 本版确定的产品决策

| 项目 | 决策 |
| --- | --- |
| 工具打开方式 | 从计划或结果编辑器打开占据主要屏幕的工作区，保留来源记录和返回位置 |
| 排板默认视图 | 点击排布后，当前板完整进入可见区域；保留放大、适合窗口和全屏能力 |
| 配液位置 | 入口紧邻板布局；摘要位于板下方；完整配置继续使用右侧抽屉 |
| 配液复制 | 一键复制当前配液方案，表格可直接粘贴到 LabNest、Excel 和 Word |
| 复核呈现 | 先显示孔位、简短原因和处理状态，详细依据按需展开 |
| 图表呈现 | 主图使用足够大的工作区，长名称自动排版，多类别支持分面和展开查看 |
| 保存方式 | 向当前记录插入或更新工具产出区块，同时保存可恢复的工具状态 |
| 打印方式 | 从已保存的完整结果生成打印内容，宽图与长表按可读性分页 |
| 发布方式 | 独立版、LabNest 内嵌版和离线版共享业务代码，记录各自构建来源 |

### 范围与优先级

P0 为本轮完整交付所需：排板与滚动改造、配液位置与复制、复核信息精简、长名称与多类别图表、计划和结果中的上下文入口、直接回填、再次编辑、完整打印，以及发布版本核对。

P1 为后续增强：离线结果包直接导入当前记录、图表显示方案复用、更多工具复用相同的接入方式。现有离线文件与工作簿上传继续可用。

本轮沿用现有计算规则，通过固定输入的回归测试核对数值与纳入孔数。生物学分组统计、显著性检验和跨板校正如需扩展，应形成单独的分析需求。此次图表分面仅改变呈现，不改变数据汇总或样本量定义。

## 3 页面入口与任务流程

### 计划页面的含义

LabNest 中，研究计划 ResearchPlan 与某一次实验 Experiment 是不同记录。工具入口覆盖两者，并明确保存目标。

| 所在页面 | 入口位置 | 保存位置 |
| --- | --- | --- |
| 具体实验的计划与准备 | Setup & samples 区域及正文插入菜单 | 当前 Experiment 的 setup 区域 |
| 研究计划编辑器 | Material & methods 区域及正文插入菜单 | 当前 ResearchPlan 的 material_methods 区域 |
| 当前实验的结果编辑器 | 结果正文附近的分析入口及插入菜单 | 当前 Result 的 analysis 区域，相关文件归入 data_media |
| Tools 工具目录 | 保留独立使用入口 | 独立工作区；用户主动选择加入哪条记录 |

日常实验优先从具体 Experiment 进入，后续分析可以直接引用该实验的布局。先在 ResearchPlan 制作布局时，方案保存在该研究计划；创建具体实验时可选用该布局版本，形成实验自己的快照，不自动分配给同一研究计划下的全部实验。

选用研究计划布局后，具体实验获得独立的布局产出 ID，保存来源研究计划、原布局 ID 和修订号；样本映射按当前实验确认。修改实验 A 的布局不会改变研究计划或实验 B 的布局。

### 从计划到排板与配液

1. 用户在当前计划点击“板布局”，选择 qPCR；当该位置已明确是 qPCR 时直接打开。
2. 系统带入已选样本、分组、顺序和已有基因信息。只有已存在的信息才预填，缺少的基因由用户输入。
3. 用户在左侧输入或调整样本与基因，点击“排布”；右侧立即显示当前整板。
4. 用户在板布局附近点击“配液”，在右侧抽屉调整体系；板下摘要同步更新，可直接复制。
5. 点击“保存到计划”，布局、配液表和可恢复方案进入当前记录；页面回到插入位置。
6. 用户后续点击区块上的“编辑布局”，恢复这次保存的方案。

首次排布后的主操作顺序固定为“查看板布局 → 配液 → 保存到计划”。配液大表和长说明不排在板布局之前。

### 从结果记录到分析与打印

1. 用户在当前实验的结果记录点击“qPCR 分析”。
2. 系统带入该实验已保存的布局版本及样本映射；多份布局时显示一个紧凑的版本选择器。
3. 用户导入仪器文件，确认无法唯一匹配的项目，处理必要的复核项。
4. 用户查看分析结果，调整图表顺序、显示名称和分面方式。
5. 点击“插入结果”，默认保存结果摘要、所选完整图表、对应结果表及可恢复的分析状态。
6. 回到同一条结果记录，补充观察和结论；点击“打印”，预览并打印完整结果内容。

在线主流程无需先下载图表或工作簿再手动上传。“调整插入内容”作为次级操作，用于选择详细表或额外图表，不在每次保存时强制弹出。

从已有 ΔCq 或 ΔΔCq 开始时，沿用现有计算路径，不强制提供孔位布局或原始 Cq，也不重建上游孔级复核。内参等来源信息作为方法记录，避免重复归一化。

### 工作区与返回行为

工具使用接近全屏的工作区，桌面端优先占满主要内容区域。顶部只保留返回、来源记录短标题、草稿状态和保存按钮。整个分析工具不放入狭窄侧栏；右侧抽屉用于配液或某一项详情。

返回时恢复原记录、原区块附近的滚动位置及编辑状态。已有未保存文字、图片和表格要随草稿保留。新记录尚无正式 ID 时，系统建立稳定的草稿标识，工具产出保存到同一个持久化草稿，并显示“已保存到草稿”。用户正式保存记录时，将正文、产出、附件和数据集统一绑定到新记录；绑定重试不能创建第二条 Result。

## 4 排板工作区需求

### 布局层级

| 区域 | 默认内容 | 交互规则 |
| --- | --- | --- |
| 顶部 | 返回、记录短标题、保存到计划 | 常态一行，避免重复应用标题和导入说明 |
| 左侧输入区 | 样本、基因、复孔数、板型、排布 | 桌面初始宽度约 300–340 px，可收起 |
| 右侧主区 | 板切换、整板、图例、当前孔信息 | 板布局优先获得高度 |
| 板附近操作 | 适合窗口、放大、配液 | 高频入口始终易于找到 |
| 板下方 | 简洁配液摘要和复制入口 | 完整配液参数在抽屉内 |

样本已由当前实验带入时，显示“已带入 12 个样本 · 编辑”一行摘要。文件导入放回左侧样本区，不在宿主与工具各保留一套大块导入区域。

### 默认整板适配

**PL01 P0** 首次生成布局、切换板型或点击“适合窗口”后，完整板框和行列坐标进入当前可见区域。96 孔板无需手动向下找最后一行。384 孔板先提供完整概览，查看孔内长名称可放大或选孔。

**PL02 P0** 可用高度由实际宿主容器决定，统一扣除 LabNest 顶栏、工具栏与必要间距。不能用接近整屏的 iframe 高度再叠加额外导入栏，造成内部工作区超过实际空间。

**PL03 P0** 适配模式随容器尺寸变化更新；用户手动放大后保留其视图，直到再次选择“适合窗口”。编辑孔位和打开详情不触发不必要的视图跳动。

**PL04 P0** 多板通过“板 1 / 3”等清楚的切换器查看。完整可见的验收针对当前板，所有板的数量和切换入口同时可见。

### 滚动与放大

**PL05 P0** 普通滚轮或触控板上下滚动执行正常滚动，不自动缩放孔板。缩放使用明确的按钮、比例控制或显式手势；保留浏览器自身缩放能力。

**PL06 P0** 桌面端每列最多保留一个主要纵向滚动区域。整板适配状态下，孔板内部不再出现用于找上下半板的纵向滚动条。指针位于板区、图例或普通留白处时，都能顺畅滚到右侧板下内容。

**PL07 P0** 放大后的平移、框选、移动孔位保持各自明确的操作方式。Esc 关闭当前详情或退出展开视图，并将焦点回到原入口。保留现有撤销和重做行为。

### 不同屏幕

桌面端以 1366×768 和 1440×900 CSS 像素为主要验收视口。平板横屏在空间允许时保持左右布局，空间不足时将输入区收起为抽屉。P0 覆盖桌面主流程、平板横屏主要操作，以及手机端的记录阅读、图表查看、产出打开与返回。手机精细拖拽排板和完整图表编辑列入 P1，按“输入 → 板布局 → 配液”分区组织，不把桌面双栏缩成极小内容。

## 5 配液位置与一键复制

### 位置和状态

**MX01 P0** “配液”入口位于板工具栏或整板相邻区域。生成布局前，用户可以设置反应体系；生成后，配液数量使用当前有效布局对应的实际孔数。

**MX02 P0** 配液摘要位于板下方，只显示配液范围、反应数、总体积及“查看配液”“复制配液”。详细计算过程和长参数解释按需展开。

**MX03 P0** 保留右侧配液抽屉。关闭抽屉后恢复原板视图，已修改参数和复制状态不丢失。抽屉在窄屏可覆盖主区，关闭后回到完整板布局。

**MX04 P0** 样本、基因、复孔数、孔位或反应体系变化后，布局与配液状态保持一致。若修改尚未应用，按钮显示“更新排布”或“更新配液”；不能复制或回填看似最新、实际来自旧布局的数值。

### 复制内容

“复制配液”默认复制当前配液方案的完整范围。多板时在按钮附近明确显示“本板”或“全部 3 板”，该范围与表中反应数一致；切换查看某块板不应悄悄改变整套配液方案的含义。

| 信息 | 复制要求 |
| --- | --- |
| 方案标题与范围 | 包含对应实验短标题、板或多板范围 |
| 基因或反应体系 | 多个基因分别成段或按列清楚区分 |
| 实际反应数 | 与当前纳入方案的实际孔数一致，区分对照及其他孔类型 |
| 单反应体积 | 保留体积数值及单位 |
| 配液余量 | 显示当前设置及最终备液量，避免用户再次重复加余量 |
| 各组分 | 组分名称、每反应体积、合计体积；必要时保留浓度 |
| 模板单独加入 | 沿用当前计算规则，清楚区分预混液与单独加入的组分 |

**MX05 P0** 复制优先同时提供制表符分隔的纯文本和兼容富文本的表格；纯文本必须能直接粘贴到 Excel 并正确分列。粘贴到 LabNest 和 Word 时可读，单位不丢失。

**MX06 P0** 复制值与当前显示和导出的配液值使用同一份计算结果及舍入规则。只在复制成功后显示短暂“已复制”；不增加弹窗确认。

**MX07 P0** 剪贴板不可用时显示“复制文本”区域，可全选复制。失败提示只说明当前操作未完成，不显示浏览器权限技术说明或大段指导。

## 6 分析中的复核信息

### 默认只呈现可操作信息

**QC01 P0** 复核区顶部显示“待复核 3 项”等数量和“仅看待复核”筛选。这里的项数按问题组计数，避免同一复孔组在多个孔上重复占满页面。

**QC02 P0** 每项默认呈现孔位或复孔组、一个简短原因、决定所需的数值以及当前处理状态。例如“B2–B4 · 复孔差异较大”，下一行给出本次极差和设置中的阈值，再提供“保留”“排除”“详情”。示例数值用于界面测试，具体阈值从本次设置读取。

**QC03 P0** 同一复孔组的同类提示聚合一次。组内某孔另有未检出、无效值等独立问题时，仍可定位到该孔。批量操作前明确显示适用孔位，单孔操作仍可使用。

### 详情与处理记录

“详情”展开完整样本与基因名、原始 Cq 或 Tm、相关复孔、仪器状态、数据来源和判定依据。常态页面不反复展示同一段规则解释。

**QC04 P0** “需复核”与“已排除”分别表示不同状态。用户保留后记录“已复核保留”，排除时可选简短原因或自行填写；恢复操作保留历史处理记录。

**QC05 P0** 简化文字不改变既有计算处理。未检出、无效值、仪器排除、人工排除与普通提示分别保存；界面可用短标签，数据层不能合并这些状态。

**QC06 P0** 改变阈值、修正数据或重新导入后，只重新打开受影响的复核项。与本次数据修订不一致的旧“已复核”状态不得继续冒充当前决定。

QC 判定、提示中的阈值、复核状态失效和保存的方法信息必须使用同一份实际生效设置。阈值改变时，计算与缓存一起更新；尚无可调阈值入口时，显示实际使用的固定阈值，不新增无效设置项。

**QC07 P0** 无有效数值、样本无法匹配等确实影响计算的问题在相关位置提示。普通方法说明与成功状态不使用醒目的常驻告警。

## 7 长名称与多类别图表

### 主图工作区

**CH01 P0** 结果区域默认显示当前基因的大图，提供基因切换和“多图概览”。主图不再被固定在约 320–430 px 宽、240–250 px 高的卡片内。

**CH02 P0** “展开查看”占据主要工作区，图表按真实数据重新排版；标题、坐标轴、图例和标签随之调整。展开、缩放和切换视图不改变计算数值。

### 长名称处理

名称排版依据真实字体和可用空间测量。常规名称优先换行；长名称过多时优先使用横向类别布局或分面。不能只通过不断缩小文字塞入所有样本。

**CH03 P0** 桌面默认坐标轴与类别标签实际显示字号不低于 12 CSS px；这一要求针对浏览器最终呈现尺寸，不只检查 SVG 中的字号属性。放大系统字体后仍可读取完整内容。

**CH04 P0** 用户可设置单独的“显示名称”。显示名称与稳定样本 ID 对应，不修改原始样本名，不因缩写相同而合并样本。名称重复时自动增加短编号或提示调整。

**CH05 P0** 屏幕详情可显示完整名称；打印和导出必须通过完整标签或名称对应表提供同样信息，不能依靠悬停才能识别。

### 多类别和多基因

**CH06 P0** 类别较多时默认采用可读的分面：每面通常 6–12 个类别，由名称长度和容器宽度决定。顶部明确显示总类别数和当前分面；允许切换到整体横向浏览。横向滚动不作为唯一查看方式。

**CH07 P0** 同一基因同一指标的分面默认保持相同坐标范围、颜色和类别顺序，方便比较。分面仅分开绘图，不重新计算均值、误差或校准基准。

**CH08 P0** 保存范围默认包含当前选定图表的全部分面。例如选择一个含 45 个样本的图，保存时保留该图全部 45 个样本。若用户只保存筛选后的部分，图标题或图注明确显示筛选范围。

**CH09 P0** 多基因支持选择要插入的图，选择结果会记住。默认保存当前选中的基因图及其全部类别，不自动把所有基因图塞进结果正文。

**CH10 P0** 图配置随分析一起保存，包括指标、数据筛选、顺序、显示名称、坐标类型、配色、误差条与分面。图与对应数据表必须引用同一次已应用的分析修订。

### 图注和科学含义

图注集中说明指标、内参与校准信息，以及误差条含义。技术复孔数量标记为技术重复；如果没有生物学重复定义，不自动形成生物学样本量或组间显著性。

已有 SVG 和 PNG 导出继续使用，增加完整布局检查。三种分析起点 Cq、ΔCq、ΔΔCq 都要覆盖本次图表改造，不能只优化其中一条路径。

## 8 工具产出回到当前记录

### 记录中的显示形态

计划保存后出现一个“板布局与配液”内容区块，默认显示板缩略图、板数、简洁配液表，以及“编辑布局”“复制配液”。详细孔位表、布局文件和配液参数放入展开内容。

结果保存后出现一个“qPCR 分析”内容区块，默认显示所选图表、简洁结果表和用户可补充的文字区域。操作保留“继续分析”“调整图表”“打印”。原始文件、完整工作簿、详细复核记录和软件构建信息集中在“数据与方法”。

该“区块”是产品概念。实现可扩展现有科学文档结构或将已有媒体、表格与数据集块组成带共同产出 ID 的区块组，不要求为每种工具再建一套文档系统。

### 回填与更新规则

**RT01 P0** 启动工具时绑定目标记录和插入位置。保存时使用这一绑定，不根据回传时用户恰好打开的页面决定写到哪里。

**RT02 P0** 新产出优先插入有效的当前位置；从固定入口启动且没有插入锚点时，写入已有的分析章节。模板没有对应章节时，在文档末尾附加分析内容区，不重新套用模板或迁移已填字段。编辑已有产出只更新相应区块，保留其附近的人工文字、图片和其他结果。一次实验可以有多个布局或分析区块。

**RT03 P0** 用户点击“插入结果”后，宿主完成图资源、数据和正文关联的保存，再返回成功回执。已有正式记录显示“已保存到当前结果”，未正式创建的记录显示“已保存到草稿”；收到成功回执后再返回原位置。

**RT04 P0** 重新编辑从区块对应的会话状态恢复，保留参数、孔处理、图配置和输入引用。保存形成该区块的新修订，不每次新建一条独立 Result。

**RT05 P0** 对采用结果模板的记录，回填不改写原有模板归属、记录类型或已填写字段。工具来源和分析方法放入产出元数据，继续复用现有 Result、ResultDataset 和附件能力 [S8]。

### 布局到分析的映射

**RT06 P0** 匹配孔位使用板标识与孔号的组合，例如“板 2 + A1”，避免多块板的同名孔相互覆盖。样本和基因使用稳定标识；原始名称与显示名称分别保存。

稳定身份应贯穿计算分组、QC、结果关联和图表；可用稳定标识或唯一内部键适配现有内核。同名但 ID 不同的样本不能合并；同一样本跨板的计算沿用明确的既有政策，不因接入改名而改变。

**RT07 P0** 仪器文件与计划存在缺孔、增孔、名称不一致或实际换孔时，只显示需要处理的差异。允许用户确认实际运行布局，并作为本次分析的布局快照保存，原计划版本保持可追溯。

**RT08 P0** 已保存分析引用明确的布局版本。后续修改实验计划不改变历史分析；用户主动重新分析时形成新修订。

## 9 打印完整结果记录

### 打印内容与入口

结果编辑器和结果查看页提供清楚的“打印”入口，延续现有 Print / PDF 功能。编辑态打印前先保存当前文字与工具区块；成功后生成对应版本的预览。保存失败时保留当前内容并提示重试，不悄悄打印旧版本。

默认打印实验标识与日期、用户写的观察和结论、所选完整图表、对应结果表，以及一段必要的方法摘要。原始逐孔明细、完整复核日志和大文件清单作为可选附表，默认不占据正文。

“结果这一页”指该结果记录的完整内容，可以生成多张纸；不以压进单张 A4 为目标。

### 排版规则

**PR01 P0** 打印从已保存数据和图资源生成，不截取屏幕可见区域；图表在屏幕中滚动、折叠或分面，不影响已选范围的完整输出。

**PR02 P0** 默认 A4 纵向。宽图按可读性拆分成多面，用户可选横向打印；每个分面保留基因、指标、坐标、图例和必要的分面标识。

**PR03 P0** 图内标签在打印成品中不低于 9 pt；名称过长使用完整换行或对应表。表格重复表头，整行不被截断；超过一页的表格可自然续页。

**PR04 P0** 主图与图注尽量同页。隐藏导航、编辑按钮、悬浮层、滚动条、未填空白模块和折叠控件。已选择打印的正文内容完整展开。

**PR05 P0** 优先使用可独立渲染的 SVG 或相应矢量输出；PNG 按最终物理尺寸生成至少 300 ppi 的图像。打印字体和图资源就绪后再进入预览，避免图表空白。

**PR06 P0** 记录页显示、下载图、对应结果表和打印件引用同一分析修订。工具服务暂时不可打开时，已经保存的图表和结果正文仍能查看和打印。

## 10 草稿 离线与必要异常

### 草稿和多窗口

**ST01 P0** 每次工具启动具有独立会话标识。草稿按当前记录和工具会话保存，不能沿用一个全局本地草稿覆盖不同实验。

**ST02 P0** 输入变更停止约 1 秒后保存本地草稿，并在宿主可用时同步。界面用“已保存草稿”或“待同步”短状态区分。只有尚未持久化且关闭会丢失内容时，才出现一次简短确认。

**ST03 P0** 同一提交重试使用同一提交标识。重复点击、网络重试和刷新后的重试不产生重复区块或重复附件关联。

**ST04 P0** 对同一区块的并发修改检测版本冲突，保留双方内容并提供“另存为新版本”。其他段落的独立修改不应被工具回填覆盖。已锁定或已归档的记录沿用 LabNest 现有修订规则。

### 离线成果回流

**OF01 P1** 两个离线工具可导出同结构的“工具结果包”，包含可恢复状态、结构化数据和静态图资源。当前计划和结果页面提供“导入工具结果”，复用在线回填逻辑。

包中原记录标识仅用于来源核对，不授权自动写入其他实验。来源与当前实验不同，仅提示这项差异，由用户选择导入当前记录。没有来源标识的独立工具结果可以加入当前记录。

旧工作簿继续可作为附件导入。只有工作簿、没有完整会话的历史文件，不显示“可恢复全部分析”；用户仍可从文件进入已有数据导入流程。

### 反馈文案

| 情况 | 界面表达 | 可用操作 |
| --- | --- | --- |
| 复制成功 | 已复制 | 自动消退 |
| 工具仍在加载 | 正在打开 | 加载完成后消失 |
| 保存尚未成功 | 尚未保存，请重试 | 重试，保留当前结果 |
| 名称无法唯一匹配 | 2 个样本待匹配 | 查看匹配 |
| 参数修改后结果过期 | 参数已修改 | 应用并更新结果 |
| 区块已被另一窗口更新 | 此结果已有新版本 | 查看最新，另存为新版本 |
| 实际配液范围未明确 | 选择配液范围 | 本板，全部板 |

## 11 信息呈现与文案规范

常态界面只保留当前操作所需的标签、数据、状态和按钮。按钮直接使用动作名称，如“排布”“配液”“复制配液”“插入结果”“继续分析”“打印”。

说明文字遵守以下规则：字段提示原则上不超过一行；同一规则在同一页面只说明一次；无问题时不展示对应异常说明；有问题时说明具体位置和下一步操作。鼠标悬停或详情中提供完整说明，触屏端也有可点击入口。

方法公式、QC 判定过程、工具版本和处理历史保留在“详情”或“数据与方法”。它们由系统保存，用户不需要为了留痕再次填写。正文不堆放通用免责声明、技术实现说明或重复的确认语句。

| 当前易出现的表达 | 调整后的默认表达 |
| --- | --- |
| 每个孔反复展开完整判定规则与来源 | B2–B4 · 复孔差异较大 · 查看详情 |
| 每次导入都显示大段文件处理说明 | 导入结果文件 |
| 分析结果只能附到新结果并说明其限制 | 插入当前结果 |
| 全屏说明及多个重复的缩放提示 | 适合窗口 · 展开 |
| 将说明段落放在整板上方 | 帮助入口，按需打开 |

## 12 数据契约与实现边界

本节用于开发对接，不呈现在日常用户流程中。字段名为拟议契约，落地时适配现有类型与数据库；核心身份、保存语义和版本关系必须保持一致。

### 启动上下文

| 信息 | 建议字段 | 约束 |
| --- | --- | --- |
| 目标记录 | ownerType、ownerId 或 draftRecordId | 类型为 research_plan、experiment 或 result；正式与草稿身份唯一 |
| 实验关联 | experimentId、researchPlanId | 从来源记录继承；研究计划阶段可暂时没有 experimentId |
| 插入目标 | sectionKey、blockId 或 anchorId | 编辑已有产出时指向该区块；新插入时预留稳定标识 |
| 工具与阶段 | toolId、phase | 明确排板或分析及计划或结果阶段 |
| 本次会话 | launchId、sessionId | 不能因页面切换改变归属 |
| 当前版本 | baseArtifactRevision、documentRevision | 检测目标区块及正文并发修改 |
| 输入与返回 | inputRefs、returnLocation | 指向样本、布局版本、文件及原页面位置 |

### 产出保存单元

| 内容 | 最低要求 |
| --- | --- |
| 身份与版本 | artifactId、artifactRevision、schemaVersion、toolId、工具构建标识 |
| 可恢复状态 | 排板会话或分析会话的完整可恢复快照，含对应格式版本 |
| 结构化数据 | 板与孔位、稳定样本和靶标标识、结果数值、单位及原始名称 |
| 图表与显示 | 图数据和图配置、所选范围、全部分面、静态图资源引用 |
| 输入来源 | 原始文件引用与摘要、布局版本、分析起点和设置 |
| 处理决定 | 复核状态、纳入与排除、理由和已有处理记录 |
| 保存信息 | 记录归属、保存时间、提交标识、关联附件与数据集 |

图资源和工作簿通过附件保存；会话和元数据使用版本化结构。原始文件摘要用于确认同一输入，不用文件名代替内容身份。技术复孔标识与生物学样本标识分别保存；缺失、未检出及无效值不转换为零。

LabNest 现有通用 PlateLayout 可承担板预览和样本关联，但不能用其有限字段替代完整 qPCR 会话。qPCR 特有的靶标、孔类型、复孔及配液设置仍由工具状态完整保存 [S8–S9]。

### 消息与保存语义

拟议最小事件包括 TOOL_READY、CONTEXT_INIT、OUTPUT_SUBMIT、SAVE_ACK 和 SAVE_ERROR。使用 iframe 时可通过 postMessage 实现；同源组件接入也遵守同样语义。

启动握手完成后再发送上下文。宿主验证消息来源、目标窗口和格式，并依据启动时的绑定决定写入目标。文件通过宿主受控附件接口保存；会话标识用于关联，不替代已有访问权限。首期无需新增通用插件市场。

保存按一个逻辑事务完成：接收产出与文件，生成或更新目标区块，关联结果数据和附件，最后返回成功回执。失败保留可重试状态，不出现正文已显示成功而图表或数据缺失的半份结果。

分析结果版本同时绑定已应用的数据快照、分析起点及本次实际生效的计算设置，不能仅用现有 appliedRevision 判断两个结果相同。提交时固化这三者及其对应的图表和结果表。

若孔位、排除等修改尚未应用，主按钮变为“应用并插入”，先完成现有应用和计算流程，再提交。已即时生效的设置变化直接纳入当前结果快照；不能把新参数与旧图拼在一起。

### 对现有项目的改造位置

| 项目 | 建议改造入口 | 复用能力 |
| --- | --- | --- |
| LabNest 工具容器 | EmbeddedLabTool、EmbeddedSampleImport、tools/[toolId] | 本站工具分发与实验来源 |
| LabNest 编辑器 | ExperimentForm、ResultForm、ScientificDocumentEditor 及研究计划编辑器 | 科学文档、章节与插入操作 |
| LabNest 保存 | analysis-results.server、Result、ResultDataset、Attachment | 现有记录关系、附件和数据集 |
| LabNest 打印 | ResultRecordDocument、DocumentPrintButton、打印样式 | 当前记录排版和 PDF 入口 |
| Planner | QpcrPlanner、PlateViewport、ReactionCalculator、globals.css | 排板、配液、撤销与视区交互 |
| Planner 状态 | plannerSession 的序列化与恢复 | 现有版本化方案，不另写一套计算 |
| Analysis | QpcrAnalysisStudio、ExpressionChart、globals.css | QC、图表和现有导出 |
| Analysis 状态 | analysis-session、schemas、图表配置 | 草稿、已应用快照、处理日志 |

现有 DOM 注入样本方式依赖 textarea 的选择器与界面文案。完成结构化上下文接入后，以稳定标识传递样本与分组；该旧路径在确认兼容后退出主流程 [S2]。

## 13 开发拆分与发布要求

### 实施顺序

| 阶段 | 工作内容 | 完成标志 |
| --- | --- | --- |
| M0 基线与契约 | 核对真实构建；确定上下文、产出和测试夹具 | 三仓库使用相同字段含义及输入实例 |
| M1 界面改造 | 排板视区、滚动、配液复制；QC 与图表改造并行 | 两工具分别通过屏幕和交互验收 |
| M2 上下文与回填 | 计划和结果入口、会话恢复、区块保存及回执 | 两条在线主流程可完整走通 |
| M3 打印与发布 | 完整图表打印、多分面、历史兼容、三种入口核对 | P0 验收全部通过，发布构建可追溯 |
| M4 后续增强 | 离线结果包、图表方案、扩展其他工具 | 对应 P1 场景独立验收 |

M1 与 M2 可在 M0 确定接口后并行。仅完成界面调整不能标记本轮整体完成；完整交付还包括回到原记录、重新编辑和打印。

### 发布一致性

独立网站、离线包和 LabNest 内嵌包从同一业务源码生成，允许宿主导航和返回按钮不同。发布记录至少包含源提交、构建时间、工具状态格式版本、集成协议版本和产物摘要。

Planner 现有 release.json 和同步脚本继续复用；Analysis 建立同等可追溯的构建信息，替代依靠固定日期离线目录识别版本的方式 [S1、S10]。内嵌静态资源按构建版本更新缓存，历史记录仍使用其保存的图与数据快照。

升级时验证已有计划、结果、工作簿附件和可恢复会话仍能打开。新包格式不兼容时保留原文件并给出具体升级或重新导入操作，不清空已有结果。
