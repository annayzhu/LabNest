# 第 4 批：实验准备清单与台面模式

日期：2026-10-15。方案见 `ROADMAP.md`（Q41–Q52 全部按推荐）。在 3002（隔离测试库 `labnest_redesign_batch1_20261015`）实现与验证；正式库未写入。

## 做了什么

- **准备清单**（`src/lib/run-preparation.ts`）：由执行视图推导，不落库。材料与用量（与完成时扣减用同一套合计，来源改写为"第 N 步"）、配液卡（本次数量与确认状态）、孔板布局（附件）、设备准备（步骤用到的工具：离心写"预冷至 4 °C · 12,000 ×g"，孵育写"预热至"，其余列设定值）、计时（步骤里的规则计时或每个时间参数块）。
  - 执行前检查（警告）：未确认体系、未填本次数量、计算待确认、库存不足（按材料名匹配，同量纲换算后比较）。
  - 执行时提示：执行时必填的实际值、执行时填写的参数。
  - 勾选"已备"和备注存在 `executionPlanJson.preparation[kind:ref]`，一次写一项，在实验锁内写入，不推进修订号（与划掉配液卡同一类台面辅助）。已结束或只读的实验不可改。
- **台面模式**（`?view=bench`，`RunBenchControls`）：手动切换，本机记住（`localStorage` `labnest:run-view`），不按设备嗅探。任何宽度都用单步卡片；≥1024px 时左侧是步骤栏（编号、完成状态、当前步、准备清单与结果的锚点），右侧是当前步；竖屏单栏。字号 1.08×，按钮与输入≥44px。"屏幕常亮"用 Screen Wake Lock（不支持的浏览器不显示；切出页面自动释放，回来再申请），"全屏"用 Fullscreen API。同一套服务端动作与修订号检查。
- **孔板布局进入实验**：实验准备里可附加规划器的"备份项目"JSON 或导出的 SVG／图片（`AttachmentLink.linkType = 'plate_layout'`）。JSON 按版本 2 结构（也兼容单板旧结构）画成只读板图：按着色维度上色、图例、悬停显示各维度值；图片直接显示；其他格式给下载链接。不改规划器，不解析 Excel。
- **记一笔**：桌面列表每步增加"记一笔"，与手机卡片一样打开快速记录并带上实验与步骤。
- **记录页**：执行记录顶部多一行"实验准备 · 已备 x/y 项；未备：…"（只在用过清单后出现；不计孔板附件）。
- **去掉的旧路径**：执行页上方单独的"本次用量（预计）"表（它的内容并入清单的"材料与用量"，含"已记录"标记）。

## 数据契约

- `executionPlanJson.preparation: { [key]: { done, doneAt?, note? } }`，可选，旧方案解析不变。
- 附件链接类型 `plate_layout`（应用层字符串，不改表）。
- `runConsumption(view, stepLabel?)`：可选的步骤标签函数；默认行为不变。

## 验证

- 单元测试：`run-preparation.test.ts`（qPCR 夹具：24 反应 → SYBR 264 µL、cDNA 48 µL；配液卡待确认；离心"预冷至 4 °C · 12,000 ×g · 第 1 步"；第 2 步计时 10 min；执行时填写 OD600；缺本次数量与库存不足的警告；勾选按键保留、未知键不计数；时长格式）。全套 723 项通过。
- 浏览器（3002，EXP-010）：
  - 填本次数量 24 后，警告消失，Proteinase K 显示 1200 µL；备注"批号 PK-0921…"写入 `preparation`，修订号不变；勾选后"已备 1/4"，数据库 `done: true, doneAt`。
  - 台面模式：点"台面模式"后地址带 `?view=bench`，本机记住；1180×820 下步骤栏 304px + 单步卡片 596px，字号 17.28px，最小目标 44px；点步骤栏第 5 步，卡片切到第 5 步；820×1180 竖屏单栏；375px 手机无溢出。控件：屏幕常亮、全屏、退出台面模式。
  - 孔板：通过 `/api/attachments` 上传规划器格式的备份 JSON（96 孔，19 个标记孔，按样本着色），清单"孔板布局"项下画出板图与图例（siNC、siLRP1-1、siLRP1-2、NTC）。
  - 记录页：出现"实验准备 · 已备 1/4 项；未备：Proteinase K、计时 第 3 步、计时 第 4 步"。
- 未验证：真机 iPad 的常亮与全屏（模拟环境只能确认按钮按能力显示）；SVG 附件的显示（代码路径与图片相同）。
