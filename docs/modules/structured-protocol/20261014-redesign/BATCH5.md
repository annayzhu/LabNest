# 第 5 批：方法知识库

日期：2026-10-15。方案见 `ROADMAP.md`（Q48–Q50 按推荐）。在 3002（隔离测试库）实现与验证；正式库未写入。

## 做了什么

- **来源与依据**（`contentJson.sources[]`，`protocol-sources.ts`）：每个版本可记录来源——文献（DOI）、网页、protocols.io、PMC 全文、书籍／手册、同事传授、Word 导入、实验整理、其他——含标题、引文、链接、许可、获取日期、备注。在元数据抽屉里维护（`ProtocolSourcesEditor`），随文档一起保存，修订自动继承；预览末尾显示"来源与依据"（`ProtocolSourcesView`，只写了 DOI 的自动给 doi.org 链接）；Word 导出在正文末尾加同名一节。`contentJson.provenance.fromExperimentIds` 记录整理自哪些实验，抽屉里按实验编号显示。
- **使用记录**（`protocol-usage.server.ts`，规程页右栏）：跨版本列出用过这份规程的实验——编号、日期、版本、体系与本次数量、步骤完成数、实际值数、偏差数、结果数、状态。只读；旧方案解析失败的实验仍列出。
- **版本对比**（`protocol-diff.ts`，`/protocols/[id]/compare?a=&b=`）：按块的稳定 id 对照，参数块显示为取值而不是 `{{id}}`；块以"第 N 步 / 第 N 步 · 说明 / 第 N 块"标注；参数按 id 对照设定（固定值、按体系的各值、执行时填写、计算）；来源逐条对照；统计修改／新增／删除。规程页"版本历史"有"版本对比"入口，每个有上一版的条目有"与上一版对比"。内存计算，不落库。
- **整理成规程修订**（`protocol-revision.ts`，`/experiments/[id]/revise`）：从实验记录的"更多"菜单进入。候选项由执行视图推导：与规程不同的实际值（同一参数取最近一次记录）和各步的偏差说明，默认全选。生成时：采纳的值写进本次所用体系对应的取值（没有该体系的值就新增一条；固定值直接替换）；偏差说明成为该步下的提示块"EXP-xxx 偏差：…"；提交为新的草稿版本（`previousVersionId` 指向本次实验所用版本，版本号自动递增且不重复，`changeSummary` 写"来自 EXP-xxx 的整理：…"），继承附件链接，写活动日志；实验与它用过的版本都不变。若规程已有更新版本，页面提示修订仍从本次所用版本派生。多份规程各生成一个草稿，完成后跳到第一个草稿的编辑器。

## 数据契约

- `protocolDocumentSchema.sources`（默认 `[]`）、`provenance`（可选）；旧文档解析不变。`tiptapToProtocolDocument` 返回空 `sources`，编辑器序列化时把文档上的来源与出处带回。
- 新路由：`/protocols/[id]/compare`、`/experiments/[id]/revise`。
- 没有新表、没有迁移。全局搜索暂不索引来源文字（留给第 6 批与检索基础设施一起做）。
