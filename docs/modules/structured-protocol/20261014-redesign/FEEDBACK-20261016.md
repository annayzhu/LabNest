## 改了什么

- **粘贴原文（JoVE 等）**：JoVE 没有公开 API，全文多为订阅内容，抓取会违反其使用条款，所以不接 API。方案设计页新增"没有 API 的网站"一栏：一键打开 JoVE、Bio-protocol、protocols.io 网页、Google Scholar 的站内搜索（新标签页），把方法原文粘贴进来（标题、链接、许可、正文），存为会话附件，之后的方法卡、比较、生成草稿与原来一样；每段成为一个步骤。只有点"归纳为方法卡"时才把文本交给模型。活动日志记 `method_pasted`。
- **`LABNEST_ATTACHMENT_ROOT` 相对路径**：现在相对工作目录解析（Docker 里仍是绝对路径，不受影响）。3002 的附件根由此生效为 `storage/redesign-batch1`；测试库引用的 14 个仍存在的文件已复制过去，其余 35 条是从正式库快照带来的旧记录，文件本来就不在本机。
- **数字显示**：全站数量显示改为"≥1 时最多两位小数；<1 时保留两位有效数字（5 µL 写成 mL 仍是 0.005，不会变成 0.01）；≥10⁹ 用科学记数"。入口是 `formatQuantity`（`calculators/quantity-format.ts`），参数块、配液卡、准备清单、记录、计算器、手表都经过它；×g、rpm 与细胞数保留千分位。存储值不变。
- **实验记录**：去掉"采用参数与来源"折叠表和"计算记录"（执行页仍有）；实际记录表的数值走同一格式。
- **空表格**：规程里只有表头、正文全空的表格（EXP-010 第 1 步那张"试剂 / 小体系"）在执行页、记录页、新建预览里不再出现；编辑器照常显示，只有表头的表保留。
- **记录页**：标题栏加"台面模式"直达执行页的台面模式（原来只有"执行"）。

- **编辑器划词浮条**（所有编辑器）：转换为（正文 / 标题 / 小标题 / 引用 / 列表）、字号、加粗、斜体、下划线、删除线、上标、下标、代码、链接、风险红、清除格式。上标／下标只在规程编辑器出现：实验和 Entry 的正文存成 Markdown 式富文本，没有上标／下标的写法，所以那两个编辑器不显示（要加得先给存储格式加 `<sup>`/`<sub>`，连带记录页、打印和 Word 导出，另开一批）。没做 Notion 的评论、表情和 AI 改写；字体按用户意见不加。

## 回答

- **不开模型也能用方案设计**：检索、抓取、粘贴、比较、生成草稿、体系换算都不需要模型；只有"归纳为方法卡"和"请模型解释"需要，关着时用"手工填写方法卡"。页面上已写明。
- **AI 页面**：现在的 `/ai` 是模型连接设置（服务、密钥、启用）＋手动粘贴模式；"建议记录"链接指向 `/actions/review`，即"提议收件箱"——所有 AI、导入、计算生成的待确认动作都在那里，确认后才写入记录。它和 `/actions` 是同一套。建议：把 `/ai` 改名为"AI 设置"并只留连接设置；提议收件箱只留 `/actions` 一个入口，从 AI 页去掉"建议记录"链接。等用户确认后再改。
  - 用户确认后已改：`/ai` 页标题、浏览器标题和侧栏项改为"AI 设置"（英文界面 AI settings），页头去掉"建议记录"与"AI 工作台"两个链接，"使用 AI"一栏去掉"查看待处理建议"（打开 AI 工作台 / 从记录生成建议 / 导入规程并提取参数保留）。提议收件箱只留 `/actions`：原来 `/actions` 不带筛选时跳到 `/ai`、带筛选时跳到 `/actions/review`，现在 `/actions` 本身就是收件箱（`?status=`、`?type=` 照旧），`/actions/review` 页面删除（404）；记录页的 Review actions、卡片上的状态与类型徽章、AI 生成后的缓存失效都指向 `/actions`。CI 的三个验收脚本（`verify-ai-module-migration`、`verify-protocol-followup`、`verify-ai-provider-adapters`）按新路由改了期望。
