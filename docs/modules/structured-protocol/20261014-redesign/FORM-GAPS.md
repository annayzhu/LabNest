## 实现记录（2026-10-18，按推荐）

### 做了什么
- **Q74 方法卡核对数值**：`checkMethodCard` 现在要求每条表述里的数值都出现在它自己的引文里，不符合的标为未核实并写明原因（“没有引文”“引文不在原文中”“数值不在引文中：…”），方法卡上直接显示原因；旧方法卡仍显示“（未核实）”。提取数值的函数移到 `source-numbers.ts`，方法卡和整理说明书的逐行核对共用同一套读法。
- **Q75 导出操作工作簿**：实验执行页“准备清单”右上角加“导出操作工作簿”，在浏览器里生成 `<实验编号>-实验准备.xlsx`：准备清单（含已备和备注）、配液卡（每个组分的加法、每反应用量、总量，分装和移液提醒）、注意事项（开始前要处理的、执行时要记录的）。数据和页面上的清单是同一份计算（`run-preparation-workbook.ts`）。
- **Q76 离线版**：`scripts/build-offline-tools.ts` 生成两个离线包，放在 `outputs/tools/portable-tools/06_Experimental_Calculator` 和 `07_Visualization_Studio`，双击 `index.html` 即可用：
  - 实验计算器：和 LabNest 里同一套组件，31 种计算、方法说明、示例、历史、导出都在；计算器之间用网址 `#/` 切换；“离线使用”面板改为说明这就是离线版；指向 LabNest 其他页面的链接显示为普通文字。图标随包放在 `icons/` 里。
  - 可视化工作台：直接从 `Visualization-studio` 仓库打包它的 `StudioApp`，不改那个仓库；82 种图、期刊和中国传统色配色、SVG/PNG 导出都在。
  - 现有打包脚本（另一个代理维护）会清空 `outputs/tools/portable-tools`，所以先运行它，再运行本脚本：`node scripts/build-portable-tools.mjs && npx tsx scripts/build-offline-tools.ts`。
- **Q77 报告合并执行记录和结果**：新建报告时，“方法与执行”按实验写入标题、所用规程与版本、实验记录里的执行内容（本次体系、各步完成情况、实际记录表、注）和偏差与事件；只属于其他体系、在实验记录里折叠的步骤和照片不写入。“结果与证据”按结果写入数值或模板字段表（含单位）、每个样本的数据表、质量状态和结果摘要。解释与结论仍是占位，由你写。已有报告不变，“刷新来源”也不改正文。
