## 2. 现状（源码事实）

- **序列已并入库存产品**（2026-10-31，Q185–Q187）：
  - 质粒、引物、siRNA 等产品各带序列；
  - 产品页显示长度、GC、Tm、分子量，可复制、看反向互补、下载 FASTA；
  - 可粘贴或导入 FASTA / CSV / TSV / XLSX；
  - `/sequences` 只做跳转，导航里没有“序列”。
- **能用的表**：`SequenceVersion` 有 `topology`（默认 linear）、`checksum`、`sourceFileName`；序列改动时会存成新版本（`product-sequences.server.ts:34`）。
- **建了没人用的表**：`SequenceFeature`（`schema.prisma:1461`：名称、类型、起止、链、备注）、`SequenceWorkflow`（alignment/assembly/crispr）、`SequenceCollection`（含 plasmid_construct）。只有 `prisma/seed.ts` 用到。
- **质粒保存成线性**：保存序列时从不设置 `topology`。
- **`validationStatus`** 是单一状态（含 `validated_recommended`，`schema.prisma:271`），表达不了 PRD 的四个维度。
- **库存的“质粒”类型**：字段有载体骨架、筛选标记；形态是甘油菌或 DNA；管理方式是“信息”。
- **代码里有、界面没用**：`translateDna`（`sequence.ts:190`）、反向互补、Tm（只到 60 nt）。
- **没有的**：GenBank / `.dna` / `.ab1` / `.seq` 读取，图谱，环形拓扑，特征注释界面，酶切，ORF，比对，峰图。
- **联动缺口**：
  - 样本不能指向质粒；
  - 计算器（连接、转染、DNA 换算）不能读产品的长度和浓度；
  - 实验只能产出样本，不能产出库存批次；
  - 产品文档附件只收 pdf/doc/docx/txt/md（`InventoryDocuments.tsx:55`）。

## 3. 对标

- **SnapGene**：桌面软件。免费的 Viewer 能看图谱、加注释；编辑和克隆模拟要付费。“Align and Verify”做测序核查（[SnapGene Viewer](https://www.snapgene.com/snapgene-viewer)）。
- **Benchling**：云端分子生物学套件，与笔记本、登记库连在一起；英文，数据在云端，按席位收费。
- **SciNote**：强项是规划和库存。公开资料里没看到它自带质粒图谱或测序核查。
- **LabNest 要做到的不同**：
  1. **证据优先**：核查结论绑定范围、标准和人工确认，四个维度分开，不给笼统的“正确”。这是 SnapGene 和 Benchling 都不强调的。
  2. **接到实验台**：核查结果挂在具体的提取批次上；转染步骤直接显示这管质粒查过哪一段；计算器取它的长度和浓度；日程里提醒“送测序”。
  3. **中文、数据在本机**：序列不发给第三方；核心计算不需要 AI。

### 4.1 位置与入口

- **工具页的第一张卡片**是“质粒工作台”。
- **质粒产品页**：“在工作台打开”。
- **直接拖文件**：拖到工作台，或拖到工具页的卡片上。
- **文档里**：“/质粒图谱”插入一张图谱快照（见[工具与实验联动](../experiment-linkage-20261101/PLAN.md) Q288）。
- **实验里**：用到质粒批次的步骤旁显示核查徽章，点开是核查报告。
- **不恢复**独立的“序列”导航。保存序列就是保存到一个质粒产品（新建或更新），遵守 Q185。

- 错配、未覆盖、低质量、人工修改同时用文字、符号或线型区分，不只靠颜色；序列用等宽字体。

### 4.3 数据：PRD 的对象落在哪里

| PRD 对象 | LabNest |
| --- | --- |
| SequenceRecord | 质粒产品 + 它的 `SequenceVersion`。新增“完整性”（已知全长 / 局部片段 / 未知），并正确保存拓扑 |
| Feature | 沿用 `SequenceFeature`，补字段：多段区间（跨起点、`join`）、`codonStart`、限定词、来源、证据类别 |
| SourceFile | 附件（`Attachment` + `AttachmentLink`），补：相对路径、SHA-256、解析器版本、兼容性摘要 |
| ReadRecord | 新表“测序读段”：来源附件、格式、碱基、质量值或“未提供”、峰位置。四通道信号存成附件里的 JSON，不放数据库 |
| Alignment | 新表“比对”：参考版本、读段、方向、坐标映射、剪裁、算法与参数、多重定位标记 |
| Primer | 引物产品（已有）；补“5′ 附加序列”和结合计算 |
| Verification | 新表“核查”：参考版本、对象（批次或样本）、检查范围与项目、质量标准、覆盖与差异、人工确认及时间、报告附件 |
| 测序资料夹（新） | 一次导入的一组文件和读段，例如“2017 年 SRGN 测序”；可以不属于任何产品，先导入，再挑参考 |

- 质粒核查不使用旧的 `validationStatus`，它继续只用于引物和 siRNA 的“推荐”状态。
- `SequenceWorkflow`、`SequenceCollection` 不复活（Q186 已决定不提供）。

### 4.4 核查流程（PRD 4.2，接到 LabNest）

1. 选参考：某个质粒产品的某个序列版本。没有参考时只能看读段，不能得出“与目标构建一致”。
2. 加读段：从测序资料夹选，或直接拖入。自动识别方向；同一次测序的 `.ab1`、`.seq` 和 ZIP 副本提示为同一来源。
3. 比对视图：低质量区、覆盖缺口、错配和插缺。
4. 点一处差异，下方展开原始峰图；反向读段可在原始方向和比对方向之间切换。
5. 指定检查范围和项目，例如“信号肽与标签之间、标签与成熟链之间”；项目可以直接来自“期望结构”（Q277）。
6. 记录人工判断：哪处差异接受、为什么。
7. 生成报告：哪些区域得到支持、哪些有差异、哪些没有证据。报告存为这个批次的核查记录，也可作为附件挂到“测序核查”实验的结果上。

### 4.5 与实验联动（细节见[工具与实验联动](../experiment-linkage-20261101/PLAN.md)）

- **批次上的徽章**：例如“已核查：信号肽–3×FLAG–成熟链连接区（Q20，2 条读段，2026-10-12 确认）”或“未核查”。
- **转染步骤**引用了质粒批次时，执行页和准备清单显示这个徽章；未核查时日程卡片上标出（多日排程 Q268）。
- **计算器**（转染、连接、DNA 换算）可以取质粒的长度和批次浓度，并写明数据来源。
- **“测序核查”实验**：挑菌 → 小提 → 送测序 → 核查。日程里“送测序”是一个事项；读段回来后，结果就是核查记录。
- **提取实验产出质粒批次**：小提、大提、甘油菌产出新的库存批次（联动文档 Q290）。

### 4.6 分期（把 PRD 的 M1–M3 重新排序）

| 期 | 内容（PRD 编号） | 理由 |
| --- | --- | --- |
| 第 1 期：看得懂、查得清 | F01 导入（FASTA、GenBank、`.seq`、`.ab1`、限定范围的 `.dna`，文件夹 / ZIP）；F03 图谱、序列、注释联动；F04 搜索与标签库；F05 六框翻译与融合结构核查；F06 Sanger 比对与峰图；F10 保存到产品与版本；F11 FASTA / GenBank / SVG / PNG / PDF 报告；F12 状态与报告 | 本次真实需求是核查历史测序（SRGN 场景要 F04 + F05 + F06）；只读和核查不依赖编辑 |

## 5. 问题与推荐

**Q271 放在哪里、什么形态。** 推荐：
- 做成 LabNest 里的“质粒工作台”：工具页第一张卡片，质粒产品页上也有入口。
- 序列仍存在库存产品上，不恢复“序列”导航（遵守 Q185–Q187）。

备选：按 PRD 先做独立离线工具，再用桥接接入 LabNest。

**Q272 第一期做什么。** 推荐：
- 4.6 的第 1 期：导入、看图谱和翻译、标签检索、融合结构核查、Sanger 比对与峰图、保存与版本、导出、核查报告。
- 编辑、两序列比较、酶切、引物和 PCR 放第二期。

备选：按 PRD 的 M1 → M2 → M3 顺序。

**Q273 测序资料夹。** 推荐：
- 拖入文件夹或 ZIP，原文件存为附件，保留相对路径、SHA-256 和解析器版本。
- 重复文件只存一份。
- `.ab1` 和同一次测序导出的 `.seq` 自动配对，可以人工改。
- 解析失败的逐项列出，可以单独重试。
- 送样表、PDF、图片只保留，不解析；不执行附件里的任何指令（F01）。
- ZIP 限制解压总量、条目数和异常路径。

备选：不建资料夹，读段只能挂在某个质粒产品下面。

**Q274 核查结果挂在哪。** 推荐：
- 挂在库存批次上：一次提取、一个克隆或一管甘油菌，因为测的是这一管，不是“这个质粒”。
- 参考序列是产品的某个序列版本。
- 产品页汇总各批次的核查状态。

备选：只挂在产品上。

### 8.1 做了什么

代码在 `src/lib/plasmid/`（约 2,100 行；另有测试 730 行、样例生成器 550 行），全部是浏览器和 Node 通用的 TypeScript，只用 LabNest 已有的 `fflate` 和 `@xmldom/xmldom`：

| 文件 | 内容 |
| --- | --- |
| `fasta.ts`、`genbank.ts` | FASTA（多记录分开）；文本 `.seq`（纯碱基或单条 FASTA，作为无质量值的读段）；GenBank 读写：拓扑、`join`/`order`/`complement`、跨起点、`<`/`>`、`codon_start`、多行限定词，写出按 NCBI 列宽 |
| `abif.ts` | `.ab1`：原始碱基（PBAS2）、Phred、峰位置、四通道信号，通道顺序按文件里的 FWO_；文件里有人工改过的碱基（PBAS1 与 PBAS2 不同）时提示；没有质量值记为“未提供” |
| `snapgene.ts` | `.dna` 子集（Q279）：序列、拓扑、特征（多段、跨起点、方向、限定词、颜色）、引物结合位点、说明；其余数据块逐项列为“未读取”；读不出序列（如压缩序列块）时拒绝导入 |
| `files.ts` | 按内容识别格式（扩展名只作参考）；ZIP 在内存里展开，先查条目数、大小和异常路径；SHA-256；同字节副本、`.ab1` 与它导出的 `.seq`、相同碱基串合为一个证据组；UTF-8 读不了时按 GBK 读 |
| `translate.ts`、`tags.ts`、`fusion.ts` | 六框翻译（含模糊碱基的密码子与 Biopython 结果相同）；标签库（FLAG、22 aa 3×FLAG、三段标准 FLAG 分开命名，HA、Myc、6×His、V5，带版本和来源），含 N 的命中不算高置信；融合结构逐项核查：存在、同框、次序、间隔、之前有无终止、连接区质量 |
| `align.ts`、`coverage.ts`、`trace.ts`、`effects.ts` | 读段对参考的局部比对（仿射空位、12-mer 种子、自动判方向、环形参考跨起点、多处可比对时提示）；错配和插缺按质量分级，同聚物长度差另行标记；覆盖度按证据组计数；F12 测序维度状态；峰图窗口可切比对方向和原始方向；Mott 剪裁；差异落在哪个特征、改变哪个密码子、是否为已注明的已知变体 |

- 课题组可以加自己的条目，所有人共用。

备选：不内置 DNA 元件，只做自定义。

**Q363 检测结果的“接受/忽略”。** 推荐：
- 检测结果单列，不自动加进注释。
- 接受一条，就作为特征加进当前序列（证据标“参考匹配”）；保存到库存时成为新版本。
- 忽略只在这次打开时有效，不存。

备选：忽略也存下来，下次打开不再提示。

**Q364 比对用哪些读段、存不存。** 推荐：
- 读段来自这次打开的文件或已存的测序资料夹，可多选；参考是当前打开的序列。
- 在后台线程里比对，界面不卡。
- B 批不存比对结果；C 批生成核查记录时，连同算法版本和参数一起存。

备选：B 批就存每次比对。

**Q365 双峰提示。** 推荐：
- 一个碱基的峰位上，第二高的通道达到最高通道的 30%，且质量 ≥ Q20 时，标“双峰，需看峰图”；阈值可调。
- 连续 3 个以上时提示“可能是混合克隆”。
- 软件只提示，不替人判定。

备选：不做双峰提示，只看质量值。

**Q366 峰图的颜色。** 推荐：
- 沿用测序仪的习惯：A 绿、C 蓝、G 黑、T 红；深色模式下 G 用浅灰。
- 每条曲线旁标碱基字母，峰顶写碱基和质量值，不只靠颜色区分。

备选：用 LabNest 自己的配色。

**Q367 “下一处差异”怎么走。** 推荐：
- 按参考坐标从左到右，跨所有读段。
- 默认只停在高质量差异和同聚物提示上；打开“包括低质量”后，低质量和模糊碱基的差异也停。
- 键盘 N、P 对应下一处、上一处。

备选：每条读段单独走一遍。

**Q368 翻译默认显示什么。** 推荐：
- 序列下方默认显示正向三个读框，≥ 100 aa 的开放阅读框加底色；反向三个读框可以切换显示。
- 选中一个 CDS 时，按 `codon_start` 显示它的翻译，并标出与文件里 `/translation` 不一致的位置。

备选：默认显示全部六个读框。
