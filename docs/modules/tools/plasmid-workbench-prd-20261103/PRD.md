## 1. 产品判断与目标

**当前工作台已经具备文件导入、序列可视化和初步测序核查能力，但尚未形成学生可以长期使用的完整编辑、设计和留档流程。** 下一步应先完成核查结果的保存与可追溯报告，再补齐编辑、酶切、引物/PCR，最后完成课题组常用的构建模拟。

产品目标是让学生在一个工作区完成“打开材料 → 看懂序列 → 修改或设计 → 查看预期产物 → 对照测序 → 老师复核 → 保存到具体材料与实验”。采用 LabNest 自己的界面、数据模型和独立实现，参考 SnapGene 的任务组织与交互效率。

### 1.1 用户与高频任务

| 用户 | 要完成的任务 | 成功的表现 |
| --- | --- | --- |
| 初学学生 | 打开老师给的质粒文件，找到目标基因、标签和阅读框 | 不需要转换多个软件；能说明选中区域、方向、来源和未确定事项 |
| 实验学生 | 修改已有构建，检查酶切、引物及预期产物 | 每一步都能预览、撤销、保存派生版本，回查输入材料 |
| 送测学生 | 将读段对照参考，逐处检查差异与连接区 | 能定位原始峰图，区分未覆盖、低质量与真实差异，提交有范围的报告 |
| 导师/带教人员 | 复核学生的构建与核查结果 | 直接打开同一个版本和证据位置，看到谁确认了什么 |
| 材料管理员 | 找到对应质粒、克隆和提取批次 | 序列版本与实物批次有明确关系，避免把一管的结果套给所有批次 |

### 1.2 分阶段目标

- **C 批：核查闭环。** 当前浏览与比对变为可保存、可复核、有范围的核查记录和报告。
- **D 批：日常工作可用。** 完成编辑、注释、两序列比较、常用酶切、手动引物与基础 PCR。完成后才评估能否承担学生的大部分日常任务。
- **E 批：常用构建流程。** 加入常规酶切连接、Gateway 单片段 BP/LR，以及随后安排的重叠组装与 Golden Gate；形成输入到产物的历史。

“替代程度”按真实任务完成情况评估，不按菜单数量或一个主观百分比宣称。多序列比对、无参考 contig 组装、染色体级浏览、NGS 原始数据分析、全部商业软件格式无损兼容、AI 自动设计不作为 C/D 批交付条件。

## 4. 信息架构与关键流程

### 4.1 工作区

保留“工具 → 质粒工作台”和库存产品页入口，不恢复独立的顶级“序列”模块。

| 区域 | 内容与交互 |
| --- | --- |
| 顶部 | 名称、产品/版本、未保存状态；打开、保存版本、导出；新建草稿与复制为新构建 |
| 左侧材料栏 | 本次文件、库存质粒、测序资料夹、关联引物、最近任务；筛选与搜索；可收起 |
| 中间主区 | 图谱、序列、特征、结构、测序核查；D 批加入比较、酶切、引物/PCR；历史与报告 |
| 右侧详情 | 选区坐标、长度、方向、翻译、注释证据、当前差异或分析参数；与主区同步 |
| 下方证据区 | 峰图、读段与质量；可展开/收起；任何选中位点都可进入 |
| 底部 | 当前选择、状态、计算进度；长计算可取消；计算失败不清除已完成工作 |

默认进入“查看”，编辑时显式进入草稿状态；初学者通过“查看质粒、核查测序、修改构建”任务入口开始。高级功能逐步展开，不要求先理解算法或内部坐标规则。

### 4.2 三条必须打通的用户流程

**流程 A：核查一批测序。** 打开参考 → 明确产品版本和实物批次 → 加读段并核对来源分组 → 指定检查范围与质量标准 → 看覆盖及连接区 → 任意位点展开峰图 → 逐项处置差异 → 人工确认 → 冻结报告 → 在批次和实验里引用。

**流程 B：修改已有质粒。** 从产品打开 → 建立草稿 → 修改序列/注释 → 预览受影响区域、阅读框和旧核查适用性 → 撤销/重做或继续 → 比较原版与草稿 → 保存为新版本或新产品 → 新版本从未核查开始。

**流程 C：设计并核对产物。** 选输入材料的固定版本 → 选方法 → 检查方向、边界、位点或引物 → 查看候选产物及不确定项 → 保存派生构建和步骤来源 → 关联实验 → 后续测序对照这个产物版本。

无参考时仅浏览读段；无批次时可保存“未关联实物的分析草稿”，不能生成某个材料已核查的徽章。

## 5. 功能需求与验收

优先级：P0=C 批必须；P1=D 批必须；P2=E 批分方法交付。下列 PW 编号供开发、测试和评审统一追踪。

### PW-01 文件导入与材料列表｜P0，已有基础

- 保留原文件、相对路径、字节哈希、解析器版本、来源时间、实际格式、读取警告与未支持字段。
- 区分字节相同副本、同一次测序的导出文件、疑似同来源、独立测序；文件夹结构不作为独立性的唯一依据。
- 重复打开文件采用“追加/替换本次材料”明确选择；有未保存草稿时不得直接丢失。失败文件可单项重试。
- .dna 明示受支持的序列、拓扑、注释、引物位点范围；无法可靠读取序列时拒绝分析。保留原始文件，不承诺写回 .dna。
- 文件解析在浏览器内进行；只有明确保存才写入 LabNest。继续限制 ZIP 条目数、解压量与异常路径。

**验收：** 混合导入成功、失败、重复文件后数量可核对；重复导入不无声覆盖草稿；未知字段列出；保存后重开保留相同来源与警告。

### PW-02 图谱、序列与选区联动｜P0 基础修正，P1 体验完善

- 支持环形/线性显示、缩放、适应窗口、按坐标定位、跨起点选择；布局切换不改变分子拓扑与完整性声明。
- 主视图、特征表、搜索结果、翻译、峰图共用选区；保留返回位置。展示坐标为 1-based 闭区间。
- 特征、翻译、酶位点、引物、覆盖分别开关。默认简洁，隐藏不等于删除；长名称可展开，重叠项可从列表定位。
- 选区复制明确为正链、反向互补或特征的生物学方向；CDS 提取遵循链、分段顺序与 codon_start。

**验收：** 反链和跨起点特征在所有视图对应同一段序列；100 个重叠注释仍可从表格定位；隐藏后重新打开不丢数据。

### PW-03 手工注释与特征库｜P1，P0 保留来源

- 新增、修改、删除注释；字段包括名称、类型、方向、分段、颜色、codon_start、限定词、证据类别和来源。
- 自动匹配与用户确认分开记录；展示匹配范围、比例、差异和库来源。近似匹配不可替换实际序列。
- 保留文件原注释；与检测结果冲突时展示并允许取舍。自定义库条目有作者/记录人、版本、来源及停用状态。
- 库更新不静默改变已保存版本的注释；“重新识别”生成可审阅的变更清单。

**验收：** 增删改和撤销后坐标、限定词、证据均恢复；同一版本重开不会因库更新自行改变；GenBank 往返保留受支持字段。

### PW-04 序列编辑与草稿保护｜P1

- 支持插入、删除、替换、粘贴、选区/整条反向互补、旋转环形起点；新建序列时显式选择拓扑和完整性。
- 编辑前后对照长度、受影响注释和 CDS 翻译；变动导致的内终止、移码或边界不确定应可见。
- 完全位于编辑区之后的注释移动；内部编辑、跨边界删除和整个注释删除分别提示。所有处理可撤销，不静默丢弃。
- 至少 100 步撤销/重做，事务同时恢复碱基、注释、拓扑和选区。重新计算受影响分析，不沿用旧结果。
- 自动保存草稿并显示保存位置/时间；正式版本显式保存且不可原地改写。刷新恢复、离开提醒、错误重试均可用。

**验收：** 连续编辑 100 步后撤销至初始状态，再重做得到同样结果；旋转起点不改变特征提取或分子内容；原文件未被改写。

### PW-05 搜索、翻译与期望结构｜P0 完善，已有基础

- DNA 搜索支持 IUPAC、两链、跨起点、允许错配数；肽段搜索支持六框。记录检索条件与全部命中。
- ORF 与翻译注明遗传密码表、显示规则、最短长度；不能把 ORF 或标签检出表述为蛋白表达证据。
- 期望结构与观察结果分栏；依次给出存在、方向/顺序、同框、间隔、内部终止和连接区证据。
- 报告冻结期望结构及特征库版本。结构修改后重新核查，旧报告保持原样。
- 片段未覆盖的位置标为“不确定/没有证据”，不把未检出直接判为不存在。

**验收：** 标签处于终止之后或另一读框时不能通过连续融合检查；仅靠参考结构不能显示连接区已获测序支持；期望结构更新不回写旧报告。

### PW-06 Sanger 比对与峰图｜P0

- 固定参考版本，保留原始碱基、质量、四通道、原始方向及比对方向；无质量值显示“未提供”。
- 允许选读段、输入坐标、点击覆盖或碱基查看任意位置。零差异、全部低质量或无可停差异时，峰图仍可打开。
- 同一个核查参数快照用于覆盖、差异置信度、导航、样式、双峰筛查与报告；质量阈值不只是显示项。
- 展示未比对成功、重复位置/多重定位、剪裁、插入、缺失、低质量和未覆盖。环形跨起点按一圈计算。
- 差异导航不漏掉待人工处理的问题；允许按全部/高质量/未处理筛选。连接区检查独立于差异列表。
- 双峰只作为人工查看提示，不自动认定混合克隆或特定突变。C 批不改原始 base calls；后续人工修订只能保存带作者和理由的覆盖层。

**验收：** 正反向峰图与原始位置互相定位；没有差异也可看任意已覆盖位置；切换 Q20/Q30 时所有视图与报告一致；没有质量不能变成高置信支持。

### PW-07 核查记录、差异处置与人工确认｜P0，新增闭环

- 建立核查任务：参考版本、实物批次/样本、读段证据组、检查范围、标准、期望结构快照、算法及参数。
- 每一差异可记录“待检查、疑似测序问题、接受为预期差异、认为样本不符、排除读段”，附理由和证据位置；处置不修改参考。
- 明确区分“检查完成”和“与参考一致”。接受预期差异后可完成检查，但报告仍列出该差异，不得将它转写为完全一致。
- 人工确认前列出未处理项、未覆盖范围、低质量、歧义定位和排除项。不能用一个总按钮掩盖未知区域。
- 最终记录冻结；修订生成后继记录并注明替代关系。参数、参考或证据变更使旧确认不适用于新任务，不删除旧结果。

**验收：** 局部读段不能产生“全序列一致”；一个批次的结果不会出现在另一批次；未处理冲突不能标为范围内一致；完成检查仍可保留明确的不符结论。

### PW-08 版本与历史｜P0 冻结，P1 浏览/比较/恢复

- 复用产品 + SequenceVersion + SequenceFeature；不另建一套平行质粒库。历史显示时间、记录人、理由、来源及版本差异。
- “恢复”从旧版本创建新版本；“复制为新构建”建立新产品并保留来源关系；同内容重复保存不增加版本。
- 保存包含基础版本 ID/指纹；多人同时提交时检测冲突，选择重载、另存或人工合并，不能最后保存者无提示覆盖。
- 保存序列与必要关联应一致完成；附件失败时清楚显示状态，可重试，不伪报全部保存成功。

**验收：** 两个浏览器编辑同一版本，第二次保存遇到冲突；恢复旧版不改变旧核查；同一版本的哈希、注释和参数可重现。

### PW-09 两条完整序列比较｜P1

- 选择两个固定版本或导入记录，给出同源区与差异表，标注参考/候选坐标、类型和适用的 CDS 影响。
- 环形起点旋转、整条反向互补后仍等价的分子报告“序列等价，仅表示不同”；等价不等于来自同一实物。
- 不同注释与碱基差异分别呈现；重复区多种同样合理的对齐应提示歧义。
- 无质量数据时只作序列比较，不产生测序质量或实验验证结论。

**验收：** 原序列、旋转表示和反向互补表示识别为等价；加入一个测试差异则准确定位；两端缺失不误报为整条一致。

### PW-10 酶切与片段分析｜P1

- 常用酶库有来源与版本；支持按名称、切点数、唯一切点、选区筛选，自定义酶集合与图谱联动。
- 展示识别位置、切割位置、切后片段长度、拓扑变化与末端类型；未知甲基化等条件显示未确定，不宣称真实反应成功。
- 支持单酶/多酶计算和理论片段示意。凝胶首先作为理论条带图，明确区别于实测凝胶及迁移精确预测。
- 不支持的切割规则明确拒绝或标记；不能用简化模型产生看似确定的结果。

**验收：** 线性/环形、零/一/多切点样例的片段数和总长度符合预期；跨起点位点不漏计；正反链及非对称切割有独立参考用例。

### PW-11 引物与基础 PCR｜P1

- 引物作为已有库存产品复用；区分完整寡核苷酸、结合段和 5′ 附加段，显示方向、定位、错配及末端情况。
- 支持手动添加、从选区创建、导入引物列表、复制/导出订购表；保存必须由用户确认。
- Tm 显示方法与输入条件，GC/长度/二级结构提示说明适用范围；不将一个评分当作实验成功概率。
- 基础 PCR 列出满足规则的候选产物、长度与方向，支持环形模板；没有产物、多产物和歧义定位均明确显示。
- 产物可以预览并保存为派生序列；保留模板版本、引物版本和规则快照。自动引物设计在 E 批单独评估。

**验收：** 正确方向、错误方向、多位点、跨起点和含附加段的模拟用例均有明确预期；输出产物序列与来源映射一致；无唯一产物时不自动择一。

### PW-12 构建模拟与来源历史｜P2

- 统一流程：输入版本 → 方法与片段顺序 → 边界检查 → 候选产物预览 → 用户保存；父材料不改写。
- E1：常规酶切连接与 Gateway 单片段 BP/LR。沿用课题组已有 Gateway 使用需求；复杂多片段 Gateway 后续交付。
- E2：重叠组装、Golden Gate 及常用突变设计；各方法独立验收，不用一个通用“拼起来”按钮掩盖规则差异。
- 展示片段方向、连接区、残留序列/位点、阅读框、不确定项与候选歧义；输出可追溯的计算产物，不表述为实验已成功。
- 每个产物有父版本、片段坐标、方法/规则版本、参数和操作人；图形历史可回到每个输入和产物。

**验收：** 每种方法有已知答案的正例与不成立例；错误方向、不兼容边界或多个候选不能静默生成唯一“正确”产物；产物重开能复现来源图。

### PW-13 图谱、核查报告与项目包导出｜P0 报告/图片，P2 项目包

- 图谱导出 SVG、PNG、PDF，保留名称、长度、拓扑、图例和所选图层；文本清晰，长标签不被裁切。
- 核查报告提供 HTML/PDF，差异表提供 CSV/TSV。内容：任务/报告 ID、参考版本与哈希、样本/批次、范围、证据组、参数、覆盖缺口、差异处置、峰图片段、结构检查、确认人/时间及未确定项。
- 明确显示“局部核查”“检查完成但存在差异”等范围和结果；未覆盖区域不得在导出时消失。
- 项目包包括 manifest、通用序列、原始材料及核查记录，带文件哈希和 schema 版本；导入前做内容和版本检查。

**验收：** 页面与报告的坐标、阈值、差异数一致；PDF 无截断；项目包在干净测试环境恢复后保留原始文件与冻结结论。C 批不以项目包为阻塞条件。

### PW-14 库存、实验和计算器联动｜P0 批次/报告，P1 计算器

- 产品保存“设计是什么”；序列版本保存“具体序列是什么”；批次/样本记录“实际测了哪一管”。
- 实验步骤引用固定版本及批次核查摘要，可点回报告和证据；产品页汇总多个批次时不得压成全产品已验证。
- 计算器取已选版本长度及已选批次浓度，显示单位、来源和更新时间；缺值要求补充，不使用任意默认浓度。
- 报告/图谱插入实验记录时保存静态快照及来源链接；源对象改变后快照不变，并提示已有新版本。

**验收：** 两批次不同结果正确分开；序列 v2 不继承 v1 的核查；更换批次后计算输入随之核对；导出实验报告仍知道用的是哪个版本。

### PW-15 学生体验与复核身份｜P0 基础，P1 角色体验

- 提供 3 个明确标注的模拟教程：查看质粒、核查读段、编辑并比较；教程不写入真实材料库。
- 中文为默认，关键术语带必要英文；搜索、空状态、错误提示、导出说明均完整翻译。
- 学生保存草稿与提交复核，带教人员记录意见并确认。是否启用正式权限取决于 LabNest 的账户体系，不默认现已具备完整角色控制。
- 若仍为共享账户，记录只能注明“人工填写的复核人”，不能称为身份认证或不可抵赖签名；正式多人复核须以现有账户体系的可靠身份为前置。
- 桌面完整编辑；平板看图、选区、峰图和复核；手机以浏览与报告为主，不把复杂序列编辑塞进窄屏。

**验收：** 学生在无需后台操作的情况下完成任务；角色启用时由服务端控制编辑/复核权限；无可靠身份时界面和报告不制造认证假象。

## 6. 核查状态模型：避免把几个问题混成一个“正确”

| 维度 | 示例取值 | 来源与规则 |
| --- | --- | --- |
| 序列完整性 | 全长声明 / 局部 / 未知 | 来自文件明确声明或用户确认，并记录来源；环形不自动等于全长 |
| 分子拓扑 | 环形 / 线性 / 未知 | 与图谱布局独立保存 |
| 特征证据 | 文件原注释 / 参考匹配 / 人工注释 / 预测 | 保留来源与版本；检出不等于表达 |
| 测序证据与核查 | 未核查 / 局部支持 / 存在未处理差异 / 指定范围核查完成 / 全参考范围核查完成 | 必须显示具体范围、覆盖与人工确认 |

另设工作流状态：草稿 → 分析完成 → 待人工复核 → 已确认 → 被后继记录替代；以及结果摘要：范围内一致、存在已说明差异、与目标不符、证据不足。工作流完成与结果一致为两个字段。

**全参考范围核查完成的必要条件：** 参考完整性来源明确；覆盖计为单圈；所有位置满足本任务标准；无未解决歧义或冲突；检查人已确认。若参考仅是片段，只能描述“该参考片段全范围”，不得写“全质粒”。

确认记录应冻结检查范围、配置和结果。旧记录继续有效地描述旧版本/旧批次，界面提示“不适用于当前版本”；不得自动把旧徽章迁移到新版本。

## 7. 数据与实现约束

### 7.1 复用和新增对象

| 对象 | 决策 | 最小信息 |
| --- | --- | --- |
| InventoryProduct / Entity | 复用 | 质粒/引物身份，关联序列、材料和实验 |
| SequenceVersion / SequenceFeature | 复用并扩展所需字段 | 碱基、拓扑、完整性来源、注释、作者、版本指纹、父版本 |
| SequencingFolder / SequencingRead / Attachment | 复用 | 原文件哈希、读段、质量、来源、解析状态与证据组 |
| PlasmidExpectedStructure | 保留产品级编辑入口 | 核查时复制快照及内容哈希；无需一开始另建复杂模板系统 |
| AlignmentRun（建议新对象） | 持久化一次计算 | 输入版本/读段、算法及参数、方向映射、差异与覆盖、计算状态、时间 |
| VerificationRecord / ReviewItem（建议新对象） | 保存核查与逐项复核 | 批次/样本、范围、结构快照、证据组快照、处置与理由、结果、确认人、报告 |
| SequenceDraft（建议新对象） | D 批草稿 | 基础版本、草稿快照、编辑操作、更新时间；与正式版本分开 |
| ConstructionRecord（建议新对象） | E 批来源关系 | 方法、父版本、片段映射、参数、产物版本；不复活已弃用的通用工作流导航 |

以上是逻辑模型，最终表名和存储拆分由实现设计确认。不要为了 PRD 先创建未使用的表。批次实际模型映射在 C 批开发前核对；若核查绑定样本，必须记录该样本与原材料的关系。

### 7.2 不变量

- 内部 0-based 半开区间；界面/报告 1-based 闭区间；跨环形起点使用多段表示，统一转换函数。
- 原始文件不可被工作台改写；原始信号与人工修订分开。公开演示/自动化验收使用模拟或已授权材料。
- 字节哈希用于识别同一文件；碱基哈希用于内容比较；二者均不能独自证明独立测序次数或实物身份。
- 同输入、同参数、同算法版本应可重现；变更算法版本不悄悄重写历史结论。
- 库更新、参考改变、阈值改变、证据排除必须显式影响新核查状态。自动保存草稿不等于发布正式版本。
- 核心解析、翻译、匹配、比对、模拟、判定不依赖 LLM。若以后添加 AI 解释，输入范围与输出用途另行设计，不能改变证据或自动确认。
- 依赖和酶/特征数据保留来源、版本及可分发依据；不提取商业软件私有数据库、图标或界面素材来充当自有资源。

### 7.3 计算与交互

沿用现有 React/Next.js 页面、TypeScript 计算模块和 Web Worker，先完善已有自研解析器与图谱。新功能以小模块接入，不整体重写工作台或引入一套平行编辑器。开发时按仓库要求先查 node_modules/next/dist/docs/ 中的相关指南。

长任务可取消并防止过期结果覆盖新选择；错误保留材料和草稿。无 Worker 的降级路径必须有规模限制或明确提示，避免大任务阻塞页面。服务端重新校验数据范围和引用关系，不仅依赖前端表单。

## 8. 非功能要求与性能目标

以下是**待实测的目标**，不是当前性能结论。首轮在实验室实际使用的桌面浏览器和一台 iPad 上记录硬件、系统及浏览器版本，再固定基准。

| 项目 | 初始验收目标 |
| --- | --- |
| 典型规模 | 1–20 kb 常规质粒、100 个注释、20 条各约 1 kb 的 Sanger 读段，作为日常基准 |
| 查看响应 | 20 kb 文件首个可交互视图目标 ≤2 秒；常用选区/切换反馈目标 ≤150 ms |
| 比对 | 上述 20 条读段目标 ≤10 秒；全程有进度且可取消，不锁住页面 |
| 扩展规模 | 100 kb / 1,000 注释作为压力测试；超出承诺范围给出提示，不默认宣称染色体级支持 |
| 保存与恢复 | 草稿目标在操作后 5 秒内保存；显示失败/离线状态；刷新恢复成功，不把未保存显示为已保存 |
| 稳定性 | 本轮新增功能无未处理控制台错误；不支持文件可诊断；计算失败可重试 |
| 可读性 | 桌面 1440/1280、平板 1024/768、手机 390 宽验证；不靠红绿单一颜色表达证据 |
| 数据保存 | 原文件/版本/报告纳入既有备份；发布前在副本恢复验证；恢复后能打开报告和原始证据 |

每项计时区分文件选择、解析、计算、渲染和网络保存；不得只报最快一次。建议固定样例重复至少 5 次并记录中位数及最慢值。涉及严格统计性能声明时另定测试规模。

## 9. 开发批次与发布门槛

| 批次 | 交付内容 | 依赖与出口 |
| --- | --- | --- |
| C0 可靠性 | R01–R05：完整性、任意峰图位置、阈值一致、证据分组、快照设计 | 先建立失败用例，再修复；不把旧报告自动迁移为新结论 |
| C1 核查留档 | PW-06/07/08 的持久化、范围、逐项处置、确认、批次关联 | 刷新/重开可复现；参考和配置不漂移；旧版结论不误用 |
| C2 交付结果 | PW-13/14 的报告、图谱、批次与实验入口；基础中文修正 | 带教人员可只用报告定位原始证据；完成一次材料闭环 |
| D1 编辑基础 | PW-02/03/04/08：完整编辑器、注释、撤销、草稿、历史 | 先保证坐标/版本不变量；再开放对正式材料的编辑 |
| D2 日常分析 | PW-09/10：完整序列比较、酶切、理论条带 | 等价分子比较和片段计算的参考用例通过 |
| D3 引物/PCR | PW-11/14：引物、候选产物、计算器数据 | 多位点和错误方向不误导；固定来源版本 |
| D4 学生试用 | PW-15：教学、复核、平板；修复试用阻断点 | 以任务完成数据决定能承担哪些日常工作 |
| E1 常用构建 | 常规酶切连接、Gateway 单片段 BP/LR、来源历史 | 每个方法独立验收，产物必须可回查输入 |

### 10.1 学生试用门槛（提案）

选择 5 名目标学生，覆盖初学与有经验者，统一使用模拟任务。先记录使用现有工具的流程和耗时，再在 LabNest 完成查看定位、局部测序核查、编辑比较、酶切分析、引物/PCR 五类任务。
