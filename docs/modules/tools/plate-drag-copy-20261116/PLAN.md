## 交互设计（推荐方案）

### 拖拽 = 交换
- 在**已选中的孔**上按下并拖动 ≥5 px → 移动；在未选中的孔或空白处按下 → 照旧框选。先点选（或框选）再拖。
- 拖动时按指针所在孔计算位移，选区形状不变。高亮两类孔：
  - 落点（选区移动后所在的孔）：主色描边 + 浅底；
  - 将被换回原处的孔（落点里原来不属于选区的孔）：琥珀色描边。
  - 任何一个孔会落到板外 → 整组标红，松手不生效，在板下方状态位写“超出孔板边界”。
- 交换规则：选区 S 平移到 D。S 里每个孔的内容去它的平移位置；D 中不属于 S 的孔，按阅读顺序（A1→A12→B1…）依次放回 S 中被腾出的孔。
  - 不重叠时就是两块完全对调，形状一致；
  - 重叠时等同轮转，例如 A1–A3 右移一格：A2–A4 是原 A1–A3，原 A4 回到 A1。
- 选区里的空孔也一起换（交换不丢、不造任何内容）。
- Esc 取消拖动；放大查看时拖到视口边缘自动滚动；一次移动 = 一步撤销。

### ⌘C / ⌘V
- ⌘C 记录所选孔及其相对位置（含 qPCR 的样本、基因、类型、复孔序号；自由板的全部参数）。
- “第一个孔”= 复制内容中按阅读顺序的第一个孔，粘贴时它对准目标孔，其余孔保持原方向和间距。
- 目标孔：指针停在某个孔上时用该孔；指针不在板上时用当前选区的第一个孔。高亮显示的就是实际会写入的孔（预览与执行用同一个函数）。
- 预览样式：将写入的空孔用主色虚线；会被覆盖的已有孔用琥珀色；越界整组标红且 ⌘V 不生效。
- 复制内容里的空孔不粘贴（不擦掉目标处已有内容）。
- 已占用孔直接覆盖，不再弹确认框；提示“已粘贴 n 孔，覆盖 m 孔，⌘Z 撤销”。
- 粘贴后选中刚粘贴的孔，可以接着拖；剪贴内容保留，可连续粘贴；Esc 或点空白处结束预览。
- 输入框获得焦点时 ⌘C/⌘V 保持文本复制粘贴，不触发孔操作。

## 颜色：决定与实现（2026-11-16）

用户回复“按推荐（浅紫）”：Q478–Q485 按推荐执行；Q477 的“固定浅紫”由 Q483 替代，改为板底跟随系统风格，默认风格是浅紫。

- **系统风格**：`src/lib/system-theme.ts` 新增“丁香浅紫”`lilac-mist`（主色 #6a55a8，配杏橙 #e08a4f）和“晴空浅蓝”`sky-mist`（主色 #2a66a8，配珊瑚 #e8875f），各配深色版本；默认风格改为 `lilac-mist`，`:root` 也跟着改用默认风格。
- **旧默认的处理**：LabNest 首次打开时会把当时的默认（月白黛青）存进本机，所以存着的“月白黛青”不一定是用户自己选的。现在只有在“外观 › 配色”里点选过风格（记为 `labnest.system-theme-chosen`），或者旧版风格键里存的就是它，才保留月白黛青；否则按新默认显示浅紫。选过其他风格的设备不受影响。（`appearance.ts` 中的 `parseAppearance` 和首屏脚本 `appearanceBootstrap` 用同一条规则。）
- **工具跟随风格**：LabNest 把当前风格的浅色色值写入 `labnest.tool-theme.v1`（`toolThemePayload`），只在变化时写入。两个板布局工具在同源下读取它，并在切换风格时通过 `storage` 事件即时更新：
  - 自由板：在 `app.js` 的 `applyHostTheme` 里映射按钮、线条、底色和板底变量；
  - qPCR：新增 `app/hostTheme.ts`，映射 `--action`、`--canvas` 等变量和板底变量。原来写死的绿色半透明描边（10 处）改为跟随 `--action`。
  - 没有共享色值时（单独打开、离线版），工具保持原来的绿色。LabNest 处于深色模式时，工具仍用浅色版本。数据孔的配色不变。
- **板底**：自由板新增圆角板底，计算孔板尺寸时扣除板底的内边距（`PLATE_TRAY_INSET`）；空孔、全部板概览的小孔板和配液预览孔都改用板底变量，打印时保留板底颜色。qPCR 的板底和空孔改为变量。
