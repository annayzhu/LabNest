## 结论

最值得借鉴的是**中文科研任务入口、数据整理、分析结果复用、项目恢复和论文拼图**。Studio 已有 82 个模块及多种变体，基础绘图并不是一片空白。下一阶段宜先让现有能力更容易找到、输入更顺畅、结果可以继续编辑，再按研究需求接入 R 分析服务。

解螺旋的 233 是工具入口总数，混合了绘图变体、数据处理、统计计算、云端数据及结果记录入口；不能用 233−82 得出缺少 151 种图。目录还包含一个“占位/不可用”入口。

本次核对了全部 233 个目录名称，深入查看 11 个工具的输入/参数页面和拼图工具。**没有执行全部工具，也没有上传科研数据或验证其数值算法、导出质量。** 页面出现“验证成功”是网站已有示例的界面状态，不是本次独立验证结论。

## 5. 建议的实施顺序

### P0：先把现有功能用顺

1. **语境正确的中文界面与场景预设。** 保留现有英文术语及中文搜索能力，补充完整双语标签；修正 Line→行距。按“比较组别、配对变化、表达差异、富集、临床模型”等任务进入。收藏、最近使用和预设只是现有注册模块的入口，不能复制一套计算逻辑。
2. **输入整理与预检。** 增加长↔宽转换、转置、列类型、缺失值统计、重复 ID、样本匹配报告；转换可撤销，原表保留。长转宽遇到重复键必须阻止或要求明确聚合规则，不能静默取均值。
3. **可恢复项目。** 补上 Config 导入与版本迁移，保存数据、映射、参数、注释表及分析来源；在不同会话重开仍得到同一图。默认本地保存，必须显式选择才发送到计算服务。
4. **复用同一结果。** 第一阶段就能支持“导入外部富集结果→气泡/柱图切换”，不必等待完整 R 后端。改变配色与排版不触发重新分析。

验收：中文任务可以找到正确图形；转换保留 ID/行数/单位并报告异常；项目往返保存后数据与参数一致；两个发布目标使用同一模块与项目格式。

### P1：让结果成为可交稿的图表

5. **论文拼图与导出。** A/B/C 面板、毫米/厘米尺寸、对齐/间距、统一图例/字体；SVG/PDF 优先保证矢量结构，TIFF 为位图出口。导出后验证物理尺寸、字体、线宽和有效分辨率。
6. **统一统计结果表。** 从已有 Bar 统计开始复用，输出效应量、区间、n、原始 P、校正 P 和检验名称；扩展批量相关时明确检验家族和 BH 校正，不以星号代替完整结果。
7. **高频缺口。** 先做基线资料表、清晰的哑铃/斜率配对预设、热图注释输入增强；Meta ROB2 等专题图按实际研究需求排期。哑铃/斜率首先评估能否复用既有几何组件，避免为每个名称新建计算模块。

### P2：可选 R 计算服务

建议保留当前浏览器作图工作区，在旁边增加可选的本地/受控服务计算层。首个用例优先选择 Counts→DESeq2→全量差异表→火山/MA/热图，再扩展 GO/KEGG/GSEA；临床建模需要另一个清楚定义的验收范围。

计算任务至少记录：输入校验和、样本/变量定义、设计公式及对比、软件/包/数据库版本、随机种子、参数、日志、全量结果与警告。后端返回有版本的结果对象，前端继续使用现有渲染器。提供可导出的脚本和环境锁定文件，使结果可复现。

不建议第一期覆盖泛癌数据库、免疫浸润、MR 和自动机器学习。这些还涉及数据版本、算法适用性、许可、混杂与验证设计。也不应重复建设已有的 qPCR 专用工具；更适合导入它的标准结果和分析来源。

## 6. “背后是不是 R”的证据边界

**有明确的 R 生态线索，但不能认定全部模块的实现。** 网站 Counts 页直接显示 DESeq2 流程，而 [Bioconductor 官方 DESeq2 页面](https://bioconductor.org/packages/release/bioc/html/DESeq2.html)说明这是在 R 中使用的计数差异分析包。因此其差异分析模块采用 R/Bioconductor 生态是有依据的判断。

分组比较页的 GITHUB 文档入口实际打开 [peach-academic/bioinfo-tools-documents-pdf](https://github.com/peach-academic/bioinfo-tools-documents-pdf)，仓库自述为 Xiantao Academic Bioinformatics Tools 文档，页面拼图页也显示仙桃学术与解螺旋会员版标识。本次没有取得服务端实现，未验证每个模块的 R 包、版本、任务执行架构或实际数值一致性；不能把 ggplot2、ComplexHeatmap、clusterProfiler 等常见包直接当作已查证的网站依赖。

对 Studio 而言，借鉴这些输入和结果流程无需先把前端改成 R。复杂统计采用经过版本锁定与独立验证的 R 实现，实时图形编辑继续用现有前端，是建议方案，并非网站后端的已知事实。

科研边界：原始 Counts 与 TPM/FPKM 必须区分；富集背景不能默认等于全基因组；配对/重复测量不能当独立样本；Cox 需检查 PH 假设；特征筛选和阈值选择必须限制在训练阶段；探索性的最佳截点不等于经过验证的预后标志物。
