## 3. 一条主线

四块不是四个孤立的功能，而是同一条线上的四个环节：

```
研究方案（为什么做）
  │  Copilot 工作流：情境卡 → 假设 → 证据链 → 设计卡 → 可行性与日程 → 审查签署
  ▼
实验（做什么）：带规程、分组、判定标准
  │  多日排程：规程的计时自动排出每天的日程段
  ▼
日程段（哪天几点做哪一段）──────▶ 手机日历、“今天”、手表
  │  工具联动：每段需要的板布局、配液卡、质粒核查
  ▼
工具成果（怎么做）：板布局、配液卡、质粒核查记录
  │  执行页按段分节，现场模式只展开当前段
  ▼
结果（证据）：qPCR / CNV 分析回流成数据集
  │
  └──▶ 回到研究方案：判定标准旁显示实际值，决定下一步
```

- **规程从哪来**：说明书和图片先按导入模板整理，再由程序识别（Copilot 第一部分）。
- **质粒从哪来**：质粒工作台读入序列和测序，核查结果挂在库存批次上。

## 4. 和 SciNote 的对比

| | SciNote | LabNest（本批设计） |
| --- | --- | --- |
| 规划 | 画布上的任务与连线，任务有到期日 | 横轴是日期，规程的计时自动排出日程段，拖动时检查时间窗 |
| 日历 | 仪表板上标出到期日 | 每段一个手机日历事件，前一晚提醒；下一期由 App 写入系统日历，改期自动更新 |
| 方案设计 | 手工 | 六步工作流：情境卡读取库存和已有结果，程序做规则检查和样本量，独立审查后签署 |
| 规程来源 | 规程库、导入 | 说明书或照片先按导入模板整理、锚点核对，再识别；整理稿可以下载成 Word |
| 分子工具 | 公开资料里没看到自带 | 质粒工作台：图谱、翻译、融合结构核查、Sanger 峰图比对；核查结果挂在批次上 |
| 工具与实验 | 任务里用 `#` 提到库存 | 带着实验打开工具，结果存回；出现在日程卡片、执行页和文档里 |

SciNote 资料来源与核对日期见[多日排程](../../modules/structured-protocol/multi-day-schedule-20261101/PLAN.md)第 3 节。
