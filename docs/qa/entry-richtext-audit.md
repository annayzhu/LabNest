# 快速记录与全站富文本专项

基线：main `bc3f3408`（包含 PR #86），2026-10-06。运行实例 `http://localhost:3001/`。

## 测试接口

依据用户任务书第 7–9 节确认的接口：真实页面的插入/标题/拖放/移动/保存按钮，Entry 创建及编辑 API、归入 API、详情及目标来源回读；有效附件投影、格式持久化与服务端并发保护。测试以这些公开行为为边界。原记录仅只读诊断，修改用隔离且带“测试”标记的数据。

## 正文权威表示

- Entry：`contentJson` 中 `labnest-markdown-v1` 文本块；`body` 为派生搜索文本，独立附件为有序附件块。
- Protocol/ResearchPlan/Experiment/Result/Report：ScientificDocument JSON，Tiptap 适配器。
- 简短输入：Compact Tiptap JSON 或 Markdown 适配器。沿用现有转换，不迁移技术栈。
- 现有系统没有登录/逐用户 ACL，按本机受信任工作空间权限边界执行；不能宣称新增了用户授权系统。

## 工作顺序

1. 原附件记录只读诊断；四缺陷基线；全入口清单。
2. 有效附件投影与上传/移动分流、标题与表格菜单、保存冲突。
3. 复用 Entry / ItemLink / ActivityLog 实现归入及冻结来源。
4. 隔离数据真实路由验收、全站页面两轮检查、生产构建与回归、PR 两轴审查、合并部署。

尚未执行的项目保持待测。真机输入/键盘/触摸和实体打印不由浏览器模拟替代。
