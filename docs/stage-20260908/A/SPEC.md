## Problem Statement
采购、库存与实验目前存在流程耦合；数量未知、瓶流转、余量观察和实际消耗需要分别表达。用户要求按已核对的独立重构计划实施，不重复开发已完成的图片保存和打印修复。

## Solution
保留原记录与账本，支持独立采购、独立库存及实验按需关联；逐瓶记录流转，明确预计与实际，只有人工确认才扣减。分批收货自行选择是否入库，导出实际购买与报价分别处理。

## User Stories
1. As a 实验人员, I want 不启用采购和库存也能记录并完成实验, so that 模块使用独立。
2. As a 采购人员, I want 独立录入或导入报价, so that 无需先建立库存。
3. As a 采购人员, I want 保留未选报价及决定理由, so that 选择可追溯。
4. As a 采购人员, I want 直接记录已下单或历史购买, so that 不补造询价。
5. As a 库管, I want 直接录入或导入当前库存, so that 不补造采购。
6. As a 库管, I want 信息追溯物料数量留空, so that 未知不会显示为零或缺货。
7. As a 库管, I want 按物料选择信息、包装或精确管理, so that 不强迫所有物料精确计量。
8. As a 库管, I want 用有日期的实际盘点启用数量管理, so that 不推算过去消耗。
9. As a 实验人员, I want 五瓶领一瓶后仓库四瓶、本人持有一瓶, so that 领用不等于耗尽。
10. As a 实验人员, I want 开封、转交、归还保持瓶编号及状态, so that 同一实物不会重复建档。
11. As a 实验人员, I want 选填估计或实测余量并保留历史, so that 两次观察差额不被当成实际消耗。
12. As a 实验人员, I want 用完后退出可用列表且保留历史, so that 可用状态准确。
13. As a Run用户, I want 同表记录未管理、信息追溯、瓶和精确库存, so that 只管理关键试剂。
14. As a Run用户, I want 预计与实际分别保存并保留来源, so that 收尾按实际确认。
15. As a Run用户, I want 不足或单位不兼容时仍保留实验记录, so that 失败扣减不丢其他内容。
16. As a Run用户, I want 重复点击、重试和离线同步不重复扣减, so that 账本可靠。
17. As a Run用户, I want 更正显式关联原交易、复制不复制交易、失败不自动退款, so that 历史不被改写。
18. As a 采购人员, I want 分批收货并逐次选择不入库、新建或补充库存, so that 不强制使用库存。
19. As a 采购人员, I want 发票与收货状态分别管理, so that 已收货可以仍待补发票。
20. As a 采购人员, I want 报销导出使用实际金额并留快照, so that 报价或后续改价不污染历史导出。
21. As a 用户, I want 导入有列映射、预览、错误定位与重复处理, so that 文件输入可审查。
22. As a 库管, I want 当前余额与新增到货分别导入并通过明确编号定位, so that 不仅按名称合并或重复累加。
23. As a 用户, I want 后补采购库存关联不再次入库, so that 历史关联不制造交易。
24. As a 维护者, I want 增量迁移保留编号、分装和旧交易, so that 旧数据兼容。
25. As a 手机用户, I want 紧凑可操作的输入和明确失败状态, so that 小屏能完成操作。

## Implementation Decisions
- 增量扩展现有库存、采购、实验及交易账本，不建立第二套消费账本。
- 未知数量独立标志；旧数量默认保持已记录。
- 实物身份与容器状态独立于余量观察；交易与观察不互推。
- 精确扣减复用现有单位转换；无必要参数时拒绝跨维度换算。
- 新写操作具备服务端校验、事务和重试标识；保留已有权限边界，不伪造当前用户。
- 文件解析、模板、预览和来源附件复用既有结构化导入。
- 金额新增定点字段，报价、实际购买和导出快照分别保留。

## Testing Decisions
- 使用用户已指定并再次确认的公开边界：真实页面操作、文件导入导出、HTTP业务接口；隔离合成数据库仅用于夹具和兼容检查。
- 按T01—T19逐项验证，不用测试数量代替功能验收。
- 以五瓶领一、250到180不推算70消耗、分批收货、单位换算、重复请求和失败后记录保持为关键已知示例。
- 页面、接口、数据库回读、浏览器模拟与真机结果分开记录。
- 适用类型检查、生产构建、双时区回归和独立代码审查。

## Out of Scope
- 本Issue只交付采购与Inventory工作线；共享UI、编辑器和四个嵌入工具仍留在阶段总清单。
- 不重新开发已合并的图片保存/打印修复。
- 不自动合并、部署或操作生产数据；不把模拟设备验收记为真机通过。
