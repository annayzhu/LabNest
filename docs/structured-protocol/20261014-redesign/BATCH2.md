## 整体逻辑

- 实验执行时记下的真实值（勾选的步骤、实际用量与读数、采用的计算结果、偏差）形成**实验执行报告**。
- 执行报告与结果一起，最终形成**实验报告**。
- 第 2 批各项都服务于这条链：步骤和真实值逐步落在“执行记录”里，偏差同步到“偏差与事件”，执行报告再汇入实验报告。

## 实现方案（2026-10-15 开工，R7 纳入）

沿用第 1 批的数据契约：只扩展，不改写旧数据。测试接口沿用已确认的三处（规程保存→重开→预览；`resolveProtocolSystem`／文档投影；建实验→选体系→执行→回读），新增的纯函数（配液卡换算、消耗汇总、大纲判定）归入第二处。

- **参数块执行交互**：执行页点参数块打开小面板。时间参数块直接倒计时，沿用步骤计时器，执行方案记下由哪个参数块启动；其他参数块记录实际值，存入原有的 `actualValues`，不改变采用值。作者在写作面板勾选“执行时必填”（参数新增 `actual: 'required'`）后，没填就不能完成该步骤。“执行时填写”的参数在步骤里就地填写，沿用体系确认的保护逻辑。
- **计算在步骤内确认**：执行页的计算卡从“实验准备”移到使用它的步骤里，确认逻辑不变；“实验准备”只保留体系、分组、本次数量。
- **配液卡**：新块类型 `mix`。组分用参数块记“每反应用量”，可以分体系；每行标“预混／单独加”；默认余量 10%、移液下限 0.5 µL，都可单卡修改。配方表可一键转换。执行页显示每反应与合计，自动写出分装操作，可打印或复制，点一行划掉。确认记入执行方案；数量、体系或数值一变，就需要重新确认；未确认的配液卡会挡住该步骤的完成。本次数量在“实验准备”里按组填写，单卡可临时改。执行时也能从一步里的参数块现场生成配液卡（标“执行时补充”），并可提议加入规程。
- **消耗与库存**：关联材料的参数块算出“每反应用量 × 本次数量”，配液卡里的组分按合计计。规程预览汇总每反应用量，执行页显示本次合计。完成实验时询问是否按本次用量扣减库存，可逐项改实际量，确认后才写入（沿用 `RunMaterialUse` 和现有的扣减确认）。旧的公式规则只作说明，不再参与计算。
- **手表**：快照带上已确认的配液卡和划掉状态。按 Q33 A：每屏一个组分；数码表冠或互点两下翻页；轻点划掉，与手机同步；最后一屏是分装操作。未确认或需重新确认的卡只显示提示。
- **执行记录（R1–R3）**：执行记录按规程分大段，每段逐步列出步骤，只显示本次体系的内容和采用值，不适用的步骤折叠。记录页和编辑页可以直接勾选、记录偏差，每步单独保存。偏差在“偏差与事件”里自动生成简洁行。新建实验时，所选规程的步骤预览也放进执行记录这一节，不再放在整页上方。
- **新建实验（E1–E5、R4、R7）**：新建时元数据面板默认打开；研究计划可以不选，之后补选时一并带出项目；方法来源改为紧凑的切换和列表；编号固定宽度；页头改为显示实验日期；编辑器节标题跟随界面语言。
- **大纲（R5）**：点击后锁定所选项，直到用户自己滚动；滚到底时末节高亮；不再在平滑滚动途中逐帧跳动。

## 新增：Entry 书写感（2026-10-15 反馈，随第 2 批验收）

用户反馈：图片调大小、输入图注不丝滑，书写感不好。查明的原因：
- 图片没有拖动调整大小，只能在右侧抽屉里改百分比数字；输入框还会把中间值弹回 100。
- 图注在右侧抽屉里输入，正文里的图注在编辑时被隐藏；每敲一个字都整篇重新序列化。
- 点图片会弹出抽屉；选中框引用了不存在的颜色变量，实际看不见。

改动（图片节点为各编辑器共用，Entry、实验记录、规程编辑器一起受益）：
- **拖动调整大小**：图片右缘有拖动把手。拖动时只在本地跟随，显示当前百分比，靠近 25/33/50/67/75/100% 时吸附（按住 Option 不吸附）；松手才写入，一次撤销即可恢复。把手也可以用键盘调节（方向键 5%，Shift 1%）。浮动工具条上有“小 / 中 / 大 / 通栏”四档。
- **图注就地书写**：图注直接写在图片下方，字号与打印一致。输入在本地进行（中文输入法安全），停顿、离开或回车时写入。回车或在末尾按下方向键，就回到正文继续写；选中图片后按回车直接进入图注。
- **不再弹抽屉**：工具条浮在图片上方，不遮挡图片；上传中在图片底边显示细进度条。
- **Entry 正文直接写在纸面上**，去掉纸面里的边框盒子。比例 1/2、1/4 不再被自动替换成 ½、¼。
- 没设过宽度的图片按比例确定宽度：横图占满一栏，竖图约 28rem 高时停住。编辑页和记录页一致，加载前也不跳动。
- 测试：新增 `document-media-resize.test.ts`（吸附、键盘步进）；浏览器实测粘贴图片、拖动缩放（单步撤销）、图注输入后回车续写、保存后记录页显示，手机宽度无溢出。

## 验收反馈（2026-10-15 第二轮）

- **步骤之间的说明对齐编号**：在空步骤上按回车会退出步骤列表，写出的说明（如“注：以下步骤在冰上操作。”）原先顶格，比编号还靠左。现在步骤编号从同一位置起排（与 Word 编号的对齐方式相同），步骤之间和之后的说明与编号左对齐；编辑器和预览一致，步骤正文位置不变。触屏上编号的点击区域伸向页边，不再盖住正文（`protocol.css`）。
- **Entry 加入“/”**：行首或空格、中文标点后输入“/”（中文输入法下的“、”“／”也可以）打开插入菜单，可用拼音首字母筛选（如 bt 标题、bg 表格、sj 时间）。只提供 Entry 的 Markdown 能保存的格式：正文、标题、小标题、引用、项目列表、编号列表、待办清单、图片、附件、表格；另有“当前时间”“日期与时间”，便于按时间记观察。选标题或列表时，当前这一行直接转换，已在列表或引用中的先移出。空行显示淡色提示“输入 / 插入……”，空标题显示“标题 / 小标题”。“/”后连续三个字符都没有匹配（如路径、比例）时，菜单自动关闭，文字原样保留。
- **与规程编辑器共用一个菜单**：插入菜单抽成共用组件（`EditorCommandMenu`、`editor-slash.ts`），规程编辑器改用它，选项和功能不变。菜单项加了图标底框和键位提示（↑↓ 选择 · ↵ 插入 · Esc 关闭，触屏不显示）。没有匹配时方向键和回车交还给正文。
- **顺带修复**：
  - Entry 里行首输入“# ”会生成一级标题，保存后变成小标题。现在“# ”是标题、“## ”是小标题，与 Markdown 读回时一致；代码块和分隔线保存后会丢失，Entry 里不再生成。
  - 规程编辑器点“＋ 插入”后搜索框拿不到焦点，接着输入的字会进入正文（第 1 批即有）。原因是菜单定位完成前处于隐藏状态，无法聚焦；现在定位后再聚焦。
  - Entry 编辑器的标题改用文档标题字体，与阅读页一致。
- 测试：新增 `editor-slash.test.ts`（何时打开菜单、查询跟随与关闭，含中文斜杠和输入法组字）。浏览器实测见下表。

## 验收反馈（2026-10-15 第三轮）：说明留在原处、全系统 Notion 式输入

用户决定：步骤之间的说明随第 2 批改为执行时留在原处（按建议）；所有编辑器改为 Notion 式输入（块手柄 ＋ / ⋮⋮），页顶 Word 式工具栏取消，功能按 Notion 分散到各处。并定下规则：**每次改动先检查新的操作路径是否与旧路径重复，重复则去掉旧的**（已记入长期记忆）。

### 说明留在原处（执行页、执行记录、新建预览、手表）
- 规程“步骤”节里不计步的说明，执行时显示在写它的位置：两步之间、第一步之前、最后一步之后。
- 写在“不适用于本次体系”的步骤之前的说明，顺延到下一个适用步骤之前（“以下步骤……”仍然读得通）。多组实验每组各显示自己体系下的说明；共同准备之前的说明只显示一次。
- 执行页：手机卡片在该步顶部用浅底框显示；桌面列表在两步之间单独一行。记录页：与勾选框左对齐的一段（角色 `note`）。新建实验预览：编号改为从同一位置起排，说明与编号对齐。手表：说明并入该步正文开头。
- **去掉的旧路径**：执行页顶部的“共同参考（不计步）”框、记录页与预览的“规程说明与参考（不计步）”折叠。空行不再算作说明。
- 实现：`projectProtocolExecution` 给出 `notePlacement`（每条说明在哪一步之前），`notesAmongSteps` 负责顺延，`runStepNotes` 按运行步骤分配；`runStepContent` 返回 `notesBefore` / `notesAfter` 取代 `common`。

### Notion 式编辑器（Entry、实验、结果、研究计划、报告、规程）
- **“/” 菜单**：所有编辑器都有。实验、结果、计划、报告的“插入”里还有指标、提示、数据集（按原插入配置）。规程的“/”增加“文字”组（正文、标题、小标题、引用、项目列表、编号列表）。
- **块手柄**：鼠标移到段落、列表、表格、图片、组件或整个规程步骤左侧出现 ＋ 和 ⋮⋮。＋ 在下方新起一行并打开“/”的搜索框（按住 ⌥ 在上方）；⋮⋮ 拖动调整顺序，点开菜单：转换为（正文、标题、小标题、引用、各类列表）、格式（对齐、缩进、字号、行距、清除格式）、规程块的“适用范围…”（步骤为“适用范围与可选…”）、上移 / 下移（⌘⇧↑ / ⌘⇧↓）、复制（新的块标识，不继承步骤、记录或条件）、删除（图片为“移除（保留原文件）”；规程块删除时一并删掉它的适用范围规则）。
- **选中文字浮条**：加粗、斜体、下划线、删除线、链接（⌘K，框内回车确定）、风险红。
- **表格浮条**：光标在表格里时出现在表格上方：＋ 行、＋ 列、－ 本行、－ 本列；规程表格另有“本列适用范围…”“转为配液卡”。
- **页头**：保存、导出 Word、打印、缩放、下载附件包（文中有附件时）。⌘⇧V 纯文本粘贴保留为快捷键。
- **触屏**：没有悬停，光标所在的块显示 ⋮⋮（只有这一个按钮，放得进手机页边；其菜单里有“在下方插入…”）。
- “#”“##”快捷输入与 Markdown 读回的层级一致的修正推广到所有编辑器；各编辑器不再生成保存后会丢失的代码块和分隔线。
