# 第 6 批：AI 辅助实验设计

日期：2026-10-15。方案见 `ROADMAP.md`（Q42–Q45、Q52 按推荐）。在 3002（隔离测试库）实现与验证；正式库未写入。

## 做了什么

入口：规程列表页"按目标设计" → `/protocols/design`。

- **6a 检索与归纳**
  - 来源适配器（`src/lib/method-sources/`）：课题组规程库（始终检索；目标按词拆开分别搜索，按命中词数排序）；protocols.io 公共 API v4（需用户自己的开发者令牌，用现有 AI 密钥加密方式保存）；Europe PMC REST（只搜开放获取且有全文的文章，先"全部词都有"再"任一词"，中文词不送出；全文 XML 只取 Materials/Methods 类小节，许可声明压成"CC BY 4.0"这样的名字）。
  - 联网只在用户点击检索或抓取时发生；服务端白名单只允许 `www.protocols.io` 与 `www.ebi.ac.uk`，15 s 超时、2 MB 上限；每次外联记入活动日志（来源、查询词、结果数或字数、许可）。
  - 抓到的原文以附件保存在设计会话下（`AttachmentLink` `method_design_session` / `method_source`），日后能复看"当时看到的是什么"。
  - 方法卡（`method-card.ts`）：固定结构——概括、用时、适用条件、样本要求、材料与设备、关键参数、操作差异与要点、风险与注意；模型必须为每条表述给出原文逐字摘录，程序逐条核对（忽略大小写、引号与空白），对不上的标"未核实"，从不静默丢弃。无模型时可手工填卡（手工内容不标未核实）。模型请求超时放宽到 4 分钟（原 1 分钟不够生成整张卡）。
  - 新表 `MethodDesignSession`（目标、条件、命中、方法卡、选择、生成的草稿）与 `MethodSearchSettings`（总开关默认关、来源、令牌）；`ProtocolVersionSourceType` 新增 `ai_design`。迁移 `20261015120000_method_design`。
- **6b 比较与选择**：勾选候选后并排对照（概括、用时、六个栏目、未核实数），写下选择理由保存；无模型参与。
- **6c 生成规程草稿**（`method-design.ts`）：新规程（编号自动分配，标签"方案设计"）+ v0.1 草稿版本（`sourceType = ai_design`）。说明节先放一条提示（来源、许可、未核实条数、"采用前逐步核对"），再写研究目标；目的节放概括；背景节放适用条件、样本要求、关键参数（未核实的逐条标出）；材料表来自方法卡；方法的每个小节成为一个步骤块，其余段落留在该步下，每个数值自动成为固定值参数块（"50/80 µL"这类按体系的值保留为文字，由作者在编辑器里定体系）；风险与要点成为步骤区末尾的警告块；来源记入"来源与依据"，`provenance.design` 记会话、命中与未核实数。草稿经编辑器往返无损。
- **6d 体系调整**（`method-scaling.ts`）：在设计页对草稿执行：新增"反应体系"维度（原体系 ▲、新体系 ■），体积、质量、物质的量按比例成为按体系取值，其余（时间、温度、浓度、设备设定）保持，细胞数、酶活单位等列为"请人工确认"，低于 0.5 µL 提示配预混液；查表值不改。模型只解释（可选，不出数字），说明写进步骤区首条提示块并标"待核"。只能对草稿执行。
- **6e 执行前检查**：由检索生成且方法卡有未核实条目的规程，准备清单警告"由方案设计生成，方法卡有 N 条未核实，请先核对原文"；草稿本身的提示块随执行页与记录显示。
