# Structured Protocol domain glossary

- **Protocol version**: the authored method at a fixed revision, including its systems, conditions, parameters and source content.
- **Selection dimension**: an independent question with explicit options, such as volume or sample property.
- **Experimental group**: a named treatment scope within one experiment, with its own confirmed selections and operation records.
- **Source group**: the source Protocol version within an experiment using more than one method; it is not an experimental group.
- **Shared preparation**: an explicitly declared experiment-level operation performed once. It cannot silently use a value from just one experimental group.
- **Execution plan**: the captured versions and explicitly adopted choices for an experiment and its experimental groups.
- **Entry source receipt**: the version and attachment references of an observation adopted when confirming a result or experiment; subsequent source edits do not change that receipt.
