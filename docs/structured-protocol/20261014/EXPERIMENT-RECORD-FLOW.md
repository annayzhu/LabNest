## 本次行为

| 用户要求 | 实现与验收 |
|---|---|
| 新建实验时默认打开元数据 | 仅新建实验启用默认展开；其他文档编辑器的默认行为保持不变。 |
| 研究计划默认为未选择，允许清空 | 普通新建入口不再取列表第一项；下拉框提供“未选择研究计划”。显式从研究计划发起的入口保留传入上下文，用户仍可清空。自定义和规程实验都可以独立保存。 |
| 删除自行记录下的英文提示 | 删除该提示，保留可选的自定义勾选步骤。 |
| 方法来源更紧凑，多个规程编号不变形 | 方法来源并排显示；修正抽屉强制单列导致的网格冲突；编号固定尺寸，长标题换行，手机操作按钮另起一行。 |
| 步骤位于执行记录内 | 新建时预览、保存后的记录页和编辑页均按“规程 → 步骤”显示；取消文档上方和结尾的重复步骤区。 |
| 可勾选步骤、简洁记录偏差 | 每次只更新指定步骤；偏差正文集中投影到“偏差与事件”。保留原有偏差类型、影响和记录人；正文保存不会覆盖 Run 状态。 |
| 选择本次体系后过滤其他体系 | 复用冻结规程与现有确定性解析器；依赖体系的步骤在确认前禁用；不适用步骤置灰、划线且不可勾选；原快照保留。无需 AI。 |
| 富文本页头显示实验日期 | 页头保留研究计划，方法来源替换为实验日期；规程版本仍可在执行分组和版本区域追溯。 |
| 左侧目录不乱跳 | 查找范围限定为所属文档；直接定位，保留点击目标直至用户继续滚动；不再观察目录自身的 DOM 更新。 |
| 观察与媒体放最后 | 编辑、预览和导出统一按章节 key 调整顺序，已有内容不重写、不丢失。 |

## 数据与交互边界

- `ExperimentStep.id`、`groupKey`、`protocolStepRef` 和冻结快照继续承担执行关联。编辑器中的操作控件不会进入可编辑正文 JSON、撤销栈或模板。
- 研究计划及项目沿用现有 nullable 字段，无数据库迁移；无计划实验可重新打开编辑。
- 单步操作沿用父实验行锁、记录锁定检查、执行方案修订和事件日志；编辑器附带文档版本，拒绝过期页面写入。勾选不会清空其他步骤或已有偏差。
- 体系准备复用原 Run 组件，嵌入编辑器时不创建嵌套 form。必填实际值和活动计时器仍通过原执行模式处理，并提供当前步骤链接。
- 偏差使用现有步骤记录作为唯一来源，在预览和导出时生成简洁正文，不另存一份可能失同步的偏差文本。
