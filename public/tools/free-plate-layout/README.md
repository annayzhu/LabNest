# Plate Layout Planner

一个无外部依赖、浏览器本地运行的多孔板布局与配液规划工具。当前支持 6、12、24、96、384 孔板；一个项目可包含 1–24 块独立物理板，可逐孔点选、鼠标框选、Shift 连续选择，为孔位添加任意文本或数值参数，并基于当前板或多板范围计算配液体系。

## 运行

直接双击 `index.html` 即可使用。也可以启动本地静态服务器：

```bash
npm run serve
```

然后访问 <http://127.0.0.1:4186/>。

## 选择方式

- 单击圆孔：只选择该孔；Ctrl/⌘ 单击可逐个增减选择。
- 鼠标拖动：框选与选择框相交的孔；按住 Ctrl/⌘ 可叠加框选。
- Shift 单击：从上一个锚点到当前孔，按从左到右、从上到下的板序连续选择。
- 单击孔板空白处：取消当前选择。
- 全选、反选、取消选择：位于孔板上方。

## 参数

- 默认提供样本、处理、剂量、时间点、重复和原始值；所有维度都可重命名、改类型、删除或新增。
- 给所选孔赋值时，只会应用已勾选的维度。

## 多板项目

- 板标签位于编辑区上方；可新建空板、复制整板、仅复制参数结构、重排或删除。
- 同规格板也是彼此独立的物理板，板名、参数、孔数据、计算结果和配液方案不会互相污染。
- “全部板概览”以同一个兼容参数统一着色，适合快速检查样本或处理条件的整体分布；精细编辑仍只作用于当前板。
- 撤销优先作用于当前板；新增、复制、重排和删除等项目结构操作使用项目级撤销。

## 配液计算

侧边栏的“配液计算”打开宽抽屉，第一版包含四个模块：

- 基础常规配液：按实验任务分为“固定比例加入试剂”“母液稀释到工作浓度”“从称量物配制溶液”。固定比例模式支持多个试剂、额外加入/最终体系两种比例含义、孔板范围或直接总量、µL/mL 混合单位、余量及小体积工作液建议。
- 转染体系配液：支持 RNAiMAX、Lipofectamine 3000、质粒与 siRNA 共转染，以及自定义单管/多管体系；可设置多个目的物、正向/反向转染、分组角色、分组余量、严格匹配的公共 Master Mix、优化变体和经确认后应用的中间工作液。RNAiMAX 默认正向转染，操作步骤会随转染方向和实际每孔体积生成：正向流程写明 A/B 管、5 min 孵育、贴壁细胞培养基与复合物体积；反向流程则先加入复合物再加入细胞悬液。换用其他品牌时不套用 RNAiMAX 的 5 min，并可按说明书修改步骤；保存后会冻结到方案与导出表中。
- 连续梯度稀释：固定倍比或指定范围，支持直接配液和逐级稀释；逐级模式会从末级向前累计下游转移量，确保每级转出后仍保留目标体积，并可预览后写入当前孔板。
- 药物浓度梯度配液与排板：每种药物可独立设置生成方式、加药体积、溶剂和母液溶剂比例；支持 vehicle 对照、固定对照孔、复孔分散、边缘孔填充和多板容量建议。

默认余量为 10%，默认最小可靠移液体积为 1 µL。配液结果可复制、导出 CSV 或打印为 PDF。只有点击“保存到项目”且状态仍为“已生效”的方案，才会进入跨板汇总和项目 XLSX；每块板会显示已保存方案，可重命名、编辑重算或经二次确认清除。浏览器本地配方库支持加载、复制修改、删除以及 JSON 导入/导出，内置配方保持只读。药物模块不进行 IC50 拟合、药物联合或协同作用分析。

“跨板配液汇总”可选择当前板、勾选板或全部板。转染体系使用统一的操作员执行计划：先按项目板序与孔位首次出现顺序列出 Mock、对照和各个目的物的独立处理液，再列出确认兼容的公共液，随后依次完成混合、孵育与正向/反向加样。含 siRNA/质粒的处理液按目的物身份跨板合并，同一容器内的 Opti-MEM 与目的物保持在一起；只有完整容器完全不含目的物且配方兼容时（例如 RNAiMAX B 液）才允许作为公共液合并。系统先把基础需求量统一换算为 µL 后相加，再对合计量加入一次统一余量，避免逐板加余量造成重复放大。界面、复制、CSV、汇总 XLSX 和项目 XLSX 共用同一份顺序与体积数据，内部 recipe key/JSON 不会显示或导出；旧版转染方案需重新计算并保存后才能进入新的执行计划。

板关联模块的孔数始终来自当前选择范围并显示为只读。如需改变孔数，应关闭配液抽屉后重新选择孔位；再次打开时，各模块尚未保存的输入会在当前页面会话中保留，只有范围与孔数会更新。“恢复默认”仅重置当前模块。

## 数据与导出

- 项目自动保存在浏览器 IndexedDB 中，并保留 `localStorage` 镜像用于兼容迁移；数据不上传网络。
- 项目 XLSX 模板：包含使用说明以及当前项目每块板的空白工作表，保留板名、规格、参数表头与单位；第一列固定为“孔位/Well”，可在 Excel 中填写后一次导入多块板。
- 当前板 CSV 模板：只为当前孔板生成 UTF-8 CSV，适合单板快速填写。
- 导入孔板表格：支持真正的多工作表 `.xlsx`、Excel 保存的 `.csv` 和制表符分隔的 `.tsv`。XLSX 中每个含“孔位/Well”表头的工作表会作为一块板导入；系统说明与汇总表不会被误当作孔板。导入前会预览识别到的板，并明确选择“新增孔板”或“覆盖当前板”。
- CSV：当前孔板的完整逐孔表，包含所有参数维度。
- SVG：当前着色方式下的矢量孔板图。
- XLSX：项目级导出包含实验总览、每块板的布局表、每块板独立的配液明细表、独立处理液、跨板公共液和逐步执行清单。布局表按 N/Z 顺序输出且默认 N；配液表保留具体方案名、每孔用量、基础需求、本板方案准备量、目标孔与操作步骤；执行表严格按“全部独立处理液 → 公共液 → 混合孵育 → 方向相关加样”排序，并为完成状态、操作者、时间、实际加入量和备注留有空列。
- JSON 备份/恢复：与孔板表格导入分开。完整工作区备份包含全部物理板、参数、孔数据、计算记录与已保存方案；恢复前会显示项目名、板数及“替换整个当前项目”的提示，旧版单板 JSON 会自动迁移。

## 测试

```bash
npm test
npm run test:visual
```

测试覆盖孔位生成、Shift 连选、矩形选择、无碰撞参数着色、固定比例与基础配液、多目的物/多管转染体系、目的物管隔离、中间工作液确认、向后累计的连续梯度、药物加药液与溶剂计算、独立多板数据模型、旧数据迁移、按目的物身份的跨板配液合并、真实执行型 XLSX 往返和配方库闭环。

真实浏览器验收使用 `scripts/acceptance/` 下的共享 harness。默认命令运行完整历史基线和所有隔离旅程；维护者也可以只运行某一条旅程：

```bash
ACCEPTANCE_JOURNEYS=plate-layout npm run test:visual:journey
ACCEPTANCE_JOURNEYS=liquid-plan-lifecycle npm run test:visual:journey
ACCEPTANCE_JOURNEYS=issue-28-merge,issue-28-split npm run test:visual:journey
```

每条隔离旅程都会清空浏览器存储、使用确定性 fixture，并在失败时生成包含旅程名称的错误及专属截图。`ACCEPTANCE_BASE_URL` 可切换到本地 Site 构建或全新解压的离线目录，而无需复制验收逻辑。模块边界和覆盖迁移见 `docs/agents/acceptance-architecture.md`。

## 科研使用边界

新增配液功能：可自定义组分的 Master Mix（模板独立加入）、按孔逐样本浓度归一化，以及定容 / 向已有液体加药 / 倍液 / 1:N / 份数稀释。反应数由所选孔决定；修改输入后需要重算，保存才会替换当前板唯一方案。归一化不会额外增加样本用量。具体模型和验证方法见 `docs/preparation-integration.md`。

离线使用：双击 `index.html`，无需安装或联网。数据保存在浏览器，不在工具文件夹里；更换文件路径或浏览器来源前，请先导出项目 JSON 备份，再在新版本导入。`release.json` 标明本包源码版本和文件校验值。

该工具负责布局、标签与确定性配液计算，不替代实验设计审查、厂商说明书或仪器软件校验。实验前应复核孔号、单位、处理条件、试剂比例和计算结果；探索性计算不应直接解释为生物学或临床结论。
